## Choosing an Android APK

| ABI label | Suitable devices |
| --- | --- |
| `arm64-v8a` | Most recent Android phones and tablets |
| `armeabi-v7a` | Older 32-bit ARM devices |
| `x86_64` | A small number of x86 devices and emulators |
| `universal` | Includes multiple architectures; broadly compatible but usually larger |

Choose `universal` when you are unsure. If a release only provides one APK, it often already includes the common architectures.

## Download and installation notes

1. Download the `.apk` installer.
2. When prompted, temporarily allow your browser or file manager to install unknown apps.
3. Disable that permission again after installation.

::caution
Avoid repackaged APK files from unknown drives, chats, or forums. Confirm that the destination matches the project source shown on this page.
::
