## Apple Silicon or Intel

| Processor | Common installer labels | Suitable devices |
| --- | --- | --- |
| Apple Silicon | `arm64`, `aarch64`, `apple-silicon` | Macs with M1, M2, M3, M4, or newer Apple chips |
| Intel | `x64`, `x86_64`, `intel` | Macs with an Intel processor |
| Universal | `universal` | Runs on both Apple Silicon and Intel, usually with a larger file size |

::tip
Open the Apple menu and choose **About This Mac**. Select ARM64 when the chip is an Apple M-series model; select x64 when the processor is Intel.
::

## Download and installation notes

1. Download the `.dmg` file for your processor.
2. Open the DMG and drag the client into the **Applications** folder.
3. If macOS blocks the first launch, verify the source first, then review **System Settings → Privacy & Security**.

::note
Apple Silicon can run some Intel applications through Rosetta, but a native ARM64 build usually provides better performance and power efficiency.
::
