## Choosing a Windows installer

| Label | Suitable devices | Recommendation |
| --- | --- | --- |
| `x64`, `x86_64`, `amd64` | Most computers with Intel or AMD processors | Usually the right option when you are unsure |
| `arm64`, `aarch64` | Windows on ARM devices, including some Snapdragon PCs | Only for ARM-based devices |
| `setup.exe`, `msi` | Users who want a standard system installation | Recommended for most users |
| `portable`, `zip` | Users who do not want to install the app | Extract and run; some system integrations may differ |

::tip
Open **Settings → System → About** and check **System type** to see whether your device uses x64 or ARM64.
::

## Download and installation notes

1. Prefer the latest stable release. Avoid files marked `alpha`, `beta`, or `nightly` unless you understand the risks.
2. Windows may display a security prompt the first time you run an installer. Verify the publisher and filename before continuing.
3. Exit an older version of the client before installing an update.

::warning
A release page may contain installers for several operating systems. Make sure the filename identifies Windows before downloading it.
::
