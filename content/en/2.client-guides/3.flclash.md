FlClash is an open-source client built with Flutter and powered by the Mihomo (Clash Meta) core. It uses the same interface on desktop and Android, which makes it a good fit if you use Clash on several devices.

| Platforms | Core | License | Price |
| --- | --- | --- | --- |
| Windows · macOS · Linux · Android | Mihomo | GPL-3.0 | Free |

## Download

FlClash is published only on its official GitHub releases page. Open the page and pick the right file from the **Assets** list of the latest release:

| Device | File name contains | Notes |
| --- | --- | --- |
| Windows PC | `windows-amd64-setup.exe` | Installer; `windows-amd64.zip` is the portable version |
| Mac (Apple silicon) | `macos-arm64.dmg` | M1 and later |
| Mac (Intel) | `macos-amd64.dmg` | Macs with Intel processors |
| Linux | `linux-amd64.deb` / `.rpm` / `.AppImage` | Pick by distribution; AppImage works everywhere |
| Android phone | `android-arm64-v8a.apk` | For almost all Android phones |
| Older Android phone | `android-armeabi-v7a.apk` | Older 32-bit devices |

::callout{icon="i-simple-icons-github" to="https://github.com/chen08209/FlClash/releases/latest" target="_blank"}
**Download FlClash from GitHub**: the official releases page, always the latest version.
::

::tip
The `android-x86_64.apk` build is only for emulators and a few x86 devices; it won't install on a normal phone. Only download from the official releases page, never from unknown file-sharing links.
::

## Install

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  Double-click `setup.exe` and follow the installer. If you see "Windows protected your PC", click **More info → Run anyway**.
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  Open the `.dmg` and drag FlClash into **Applications**. If macOS blocks it on first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**.
  :::

  :::tabs-item{label="Linux" icon="i-simple-icons-linux"}
  ```bash
  # Debian / Ubuntu
  sudo apt install ./FlClash-*-linux-amd64.deb

  # Fedora / openSUSE
  sudo dnf install ./FlClash-*-linux-amd64.rpm
  ```
  :::

  :::tabs-item{label="Android" icon="i-simple-icons-android"}
  Tap the downloaded `.apk` to install it. If Android blocks apps from unknown sources, allow your browser or file manager to install apps when prompted.
  :::
::

## Setup

::steps
### Get your subscription link

FlClash is only a client and does not include any servers. Sign in to your provider's dashboard and copy your subscription link (usually under "Subscribe" or "Copy subscription URL").

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Add a profile

Click the **Profiles** icon in the sidebar, then click **+** in the bottom-right corner.

![Open Profiles in FlClash and click Add](/images/flclash/install1.webp)

Choose **URL** from the menu.

![Choose to add a profile from a URL in FlClash](/images/flclash/install2.webp)

Paste the subscription link and click **Submit**.

![Paste the subscription link in FlClash and submit](/images/flclash/install3.webp)

When a profile card appears with data usage, the import worked.

![Subscription imported successfully in FlClash](/images/flclash/install4.webp)

### Start the proxy

Go back to the **Dashboard**, set the outbound mode to **Rule**, make sure **System proxy** is on, and click the **▶** button in the bottom-right corner. On Android, allow the VPN permission request the first time.

![Start the proxy from the FlClash dashboard](/images/flclash/install6.webp)

### Choose a server

Open **Proxies** and pick a server with low latency, or keep automatic selection. If your usual websites load in the browser, you're done.
::

::tip
Older FlClash versions have no start button. Just turn on the **System proxy** switch on the dashboard.

![Turn on the system proxy switch in older FlClash versions](/images/flclash/install5.webp)
::

## Advanced settings

### Virtual network adapter (TUN mode)

The **Virtual NIC** (TUN) switch on the dashboard captures traffic from apps that ignore the system proxy, such as games and command-line tools. On a computer, it may need administrator rights. Use either the system proxy or TUN, not both. See [Advanced Settings](/en/installation-guide/advanced-settings).

### Update subscriptions

Click the refresh button in the top-right corner of **Profiles** to update all subscriptions.

## FAQ

::accordion
  :::accordion-item{label="The import fails after I click Submit."}
  Make sure the link was copied completely, the subscription hasn't expired, and your device is online. If it still fails, see [Troubleshooting](/en/installation-guide/troubleshooting).
  :::

  :::accordion-item{label="Android says “There was a problem parsing the package”."}
  You probably downloaded the wrong build, for example the `x86_64` APK on a phone. Download `android-arm64-v8a.apk` instead.
  :::

  :::accordion-item{label="macOS says the app “is damaged and can’t be opened”."}
  Open Terminal, run the command below, and open FlClash again:

  ```bash
  sudo xattr -r -c /Applications/FlClash.app
  ```
  :::

  :::accordion-item{label="The proxy is running, but websites still don't load."}
  Switch to a server that passes the latency test, make sure the outbound mode is Rule, and disable any other proxy extensions in your browser.
  :::
::
