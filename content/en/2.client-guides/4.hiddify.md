Hiddify is an open-source proxy client for every major platform, built on the sing-box core. It reads Clash / Mihomo, sing-box, and V2Ray subscriptions directly, keeps the interface simple, and connects in one tap. It's a good choice if you don't want to deal with many settings.

| Platforms | Core | License | Price |
| --- | --- | --- | --- |
| Windows · macOS · Linux · Android · iOS | sing-box | GPL-3.0 | Free |

## Download

The desktop and Android versions are published on the official GitHub releases page, and the iOS version is on the App Store. On GitHub, pick the right file from the **Assets** list of the latest release:

| Device | File name | Notes |
| --- | --- | --- |
| Windows PC | `Hiddify-Windows-Setup-x64.exe` | Installer; `Portable-x64.zip` is the portable version |
| Mac | `Hiddify-MacOS.dmg` | Works on Apple silicon and Intel |
| Linux | `Hiddify-Linux-x64.AppImage` | `Debian-x64.deb` and `rpm-x64.rpm` are also available |
| Android phone | `Hiddify-Android-universal.apk` | Universal build; pick this if you're unsure |

::callout{icon="i-simple-icons-github" to="https://github.com/hiddify/hiddify-app/releases/latest" target="_blank"}
**Download Hiddify from GitHub**: the official releases page for desktop and Android.
::

::callout{icon="i-simple-icons-apple" to="https://apps.apple.com/app/hiddify-proxy-vpn/id6596777532" target="_blank"}
**Get Hiddify on the App Store**: the free iPhone and iPad app, listed as "Hiddify Proxy & VPN". It isn't available in the mainland China App Store.
::

## Install

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  Double-click `Setup-x64.exe` and follow the installer. If you see "Windows protected your PC", click **More info → Run anyway**.
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  Open the `.dmg` and drag Hiddify into **Applications**. If macOS blocks it on first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**.
  :::

  :::tabs-item{label="Linux" icon="i-simple-icons-linux"}
  ```bash
  chmod +x Hiddify-Linux-x64.AppImage
  ./Hiddify-Linux-x64.AppImage
  ```
  :::

  :::tabs-item{label="Android" icon="i-simple-icons-android"}
  Tap the downloaded `.apk` and allow installs from unknown sources when prompted. See [Hiddify Android](/en/client-guides/hiddify-android) for the full Android guide.
  :::
::

## Setup

::steps
### Copy your subscription link

Hiddify is only a client and does not include any servers. Sign in to your provider's dashboard and copy your subscription link.

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Add from clipboard

Open Hiddify, click **New Profile**, and choose **Add from clipboard**. Hiddify reads the link you just copied.

![Add a subscription from the clipboard in Hiddify](/images/hiddify/install2.webp)

### Turn on auto-update

Open the profile details, click **Auto update**, enter an interval (for example, 12 hours), confirm, and click **Save** in the top-right corner. Server changes will now sync automatically.

![Open the auto-update setting in Hiddify](/images/hiddify/install3.webp)

![Enter the auto-update interval in Hiddify](/images/hiddify/install4.webp)

### Connect

Go back to the home screen and click the large button in the middle. When it shows "Connected" with a latency value, you're done. To switch servers, open **Proxies** in the sidebar.

![Click the button to connect in Hiddify](/images/hiddify/install5.webp)
::

## Advanced settings

### Service mode and TUN

By default, Hiddify works as a system proxy. If games or command-line tools don't go through the proxy, open **Config Options** and set **Service Mode** to **VPN**. This works like TUN mode and captures all traffic. VPN mode may need administrator rights on a computer.

Config Options also include IPv6 and DNS settings. If you're not sure what they do, keep the defaults. For background, see [Advanced Settings](/en/installation-guide/advanced-settings).

## FAQ

::accordion
  :::accordion-item{label="Nothing happens when I click “Add from clipboard”."}
  Make sure the clipboard contains the full subscription link starting with `https://`. You can also choose **Manual entry** and paste the link.
  :::

  :::accordion-item{label="It says Connected, but websites don't load."}
  Open **Proxies** and switch to a server with lower latency. If every server times out, check in your provider's dashboard whether your plan has expired, then update the subscription. See [Troubleshooting](/en/installation-guide/troubleshooting) for more.
  :::

  :::accordion-item{label="I see several apps named Hiddify on the App Store."}
  Look for the app named "Hiddify Proxy & VPN", or use the App Store link on this page to avoid look-alike apps.
  :::
::
