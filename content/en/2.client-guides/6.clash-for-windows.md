Clash for Windows (CFW) was once the most popular Clash desktop client. In November 2023, its developer stopped work on it and deleted the official repository. It has received no updates since.

::warning
**Clash for Windows is no longer maintained, and this site no longer offers it for download.** CFW is closed source and its official channels are gone, so every installer still circulating is a third-party re-upload that may have been tampered with. New users should go straight to the open-source, actively maintained [Clash Verge Rev](/en/client-guides/clash-verge).
::

| Item | Status |
| --- | --- |
| Last version | 0.20.39 |
| Source | Closed source; official repository deleted |
| Modern protocols | No VLESS, Hysteria2, TUIC, etc. |
| Recommended replacement | [Clash Verge Rev](/en/client-guides/clash-verge) (Windows / macOS / Linux) |

## Why you should switch

- **No security updates**: problems found after it was discontinued will never be fixed.
- **Outdated protocols**: its old Clash core can't use servers with newer protocols, and a single unsupported server can make the whole profile fail to import.
- **A better replacement exists**: Clash Verge Rev looks and works much like CFW, so there's almost nothing new to learn.

## Migrate to Clash Verge Rev

::steps
### Install Clash Verge Rev

Download and install it from the official GitHub page by following the [Clash Verge Rev guide](/en/client-guides/clash-verge).

### Quit Clash for Windows

Turn off **System Proxy** in CFW, then quit it from the system tray so both clients don't change the system proxy at the same time.

### Import the same subscription

A subscription link works in any Clash client. Paste the link you used in CFW into **Profiles** in Clash Verge Rev, import it, and turn on the system proxy.
::

::tip
Once everything works in the new client, you can uninstall Clash for Windows from Windows Settings.
::

## For existing users

If you're still using an installed copy of CFW for now, here are the basics.

::steps
### Import a subscription

Click **Profiles** in the sidebar, paste the subscription link into the **Download from a URL** box at the top, and click **Download**.

![Paste a subscription and click Download on the Profiles page of Clash for Windows](/images/clash-for-windows/install1.webp)

When a new profile appears with data usage and an expiry date, the import worked. Click it to select it.

![Subscription imported in Clash for Windows](/images/clash-for-windows/install2.webp)

### Turn on the system proxy

Click **General** in the sidebar and turn on **System Proxy**.

![Turn on System Proxy on the General page of Clash for Windows](/images/clash-for-windows/install3.webp)
::

### TUN mode and IPv6

You can turn on **IPv6** and **TUN Mode** on the **General** page. TUN mode requires the service: click **Manage** next to **Service Mode** to install it first.

::div{.grid.gap-4.sm:grid-cols-2}
![Enable IPv6 in Clash for Windows](/images/clash-for-windows/open-ipv6.webp)

![Enable TUN mode in Clash for Windows](/images/clash-for-windows/open-tun.webp)
::

## FAQ

::accordion
  :::accordion-item{label="Downloading the subscription fails and the profile won't load."}
  This is the most common CFW problem. The subscription contains servers using newer protocols such as VLESS or Hysteria2, the old core can't read them, and the whole profile fails to parse. CFW can't be upgraded, so the only fix is to switch to a client that supports these protocols, such as [Clash Verge Rev](/en/client-guides/clash-verge).

  ![Clash for Windows profile import error](/images/clash-for-windows/node-pull-error.webp)
  :::

  :::accordion-item{label="Can I use Clash for Windows on a Mac?"}
  CFW used to have a macOS build, but it's discontinued as well. Mac users should use [Clash Verge Rev](/en/client-guides/clash-verge), which supports both Apple silicon and Intel Macs.
  :::

  :::accordion-item{label="System Proxy is on, but I still can't get online."}
  Switch to another server on the **Proxies** page and make sure the mode is Rule. If it still doesn't work, the protocol is probably unsupported, so migrate to a newer client. See [Troubleshooting](/en/installation-guide/troubleshooting) for more.
  :::
::
