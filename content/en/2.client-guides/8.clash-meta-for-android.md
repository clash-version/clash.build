Clash Meta for Android (CMFA) is maintained by the MetaCubeX team as the open-source successor to the discontinued Clash for Android. It uses the Mihomo (Clash Meta) core, supports newer protocols such as VLESS, Hysteria2, and TUIC, and looks almost identical to the old app. It's the most widely used Clash client on Android today.

| Platform | Core | License | Price |
| --- | --- | --- | --- |
| Android | Mihomo | GPL-3.0 | Free |

## Download

CMFA is published only on its official GitHub releases page. Open the page and pick the right file from the **Assets** list of the latest release:

| Device | File name contains | Notes |
| --- | --- | --- |
| Most Android phones | `meta-arm64-v8a-release.apk` | Almost every phone made since 2017 |
| Not sure | `meta-universal-release.apk` | Universal build; larger, but works on any device |
| Older Android phones | `meta-armeabi-v7a-release.apk` | Older 32-bit devices |

::callout{icon="i-simple-icons-github" to="https://github.com/MetaCubeX/ClashMetaForAndroid/releases/latest" target="_blank"}
**Download Clash Meta for Android from GitHub**: the official releases page, always the latest version.
::

::tip
Huawei and Honor phones: HarmonyOS 4 and earlier can install APKs directly. For HarmonyOS NEXT, see [Clash Box](/en/client-guides/clash-box) or [Install Clash with ZhuoYiTong](/en/client-guides/zyt-clash).

## Setup

::steps
### Install the app

Tap the downloaded `.apk` to install it. If Android blocks apps from unknown sources, allow your browser or file manager to install apps when prompted.

### Get your subscription link

CMFA is only a client and does not include any servers. Sign in to your provider's dashboard and copy your subscription link (usually under "Subscribe" or "Copy subscription URL").

![Copy the subscription link from your provider's dashboard](/images/copy-sub.webp)

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Import from URL

Open CMFA and tap **Profiles** → **+** in the top-right corner → **URL**. Paste the subscription link into the URL field, enter any name, and tap the **Save** icon in the top-right corner.

:::div{.grid.gap-4.grid-cols-2.sm:grid-cols-3}
![Tap Profiles in CMFA](/images/clash-meta-for-android/copy-install1.png)

![Tap the plus button in CMFA](/images/clash-meta-for-android/copy-install2.png)

![Choose Import from URL in CMFA](/images/clash-meta-for-android/copy-install3.png)

![Paste the subscription link in CMFA](/images/clash-meta-for-android/copy-install4.png)

![Save the profile in CMFA](/images/clash-meta-for-android/copy-install5.png)
:::

After saving, go back to the profile list and tap the profile you just imported to select it.

### Start the proxy

Go back to the home screen and tap **Stopped** to start. The first time, Android asks for VPN permission. Tap **OK**. When the button changes to **Running**, you're connected.

:::div{.grid.gap-4.grid-cols-2}
![Tap Stopped to start the proxy in CMFA](/images/clash-meta-for-android/copy-install6.png)

![CMFA showing Running](/images/clash-meta-for-android/copy-latest.png)
:::

### Choose a server

Tap **Proxy** on the home screen and choose automatic selection or a low-latency server. Tap the lightning icon in the top-right corner to test all servers at once.
::

## Advanced settings

### Per-app proxy

To send only some apps through the proxy, or to exclude certain apps such as banking apps:

1. Go to **Settings → Network**.
2. Under **Access Control Mode**, choose to allow only selected apps or to exclude selected apps.
3. Select the apps in the access control app list, then restart the proxy.

### Update the subscription

Open **Profiles** and use the menu next to the subscription to update it. You can also set an **Auto Update** interval when editing the profile.

## FAQ

::accordion
  :::accordion-item{label="Installation fails with “There was a problem parsing the package”."}
  The APK usually doesn't match your phone's architecture, or the download was incomplete. Download `meta-universal-release.apk` and try again.
  :::

  :::accordion-item{label="Importing the subscription fails."}
  Make sure the link was copied completely, the subscription hasn't expired, and your phone is online. If it still fails, see [Troubleshooting](/en/installation-guide/troubleshooting).
  :::

  :::accordion-item{label="It shows Running, but websites still don't load."}
  Switch to a server that passes the latency test on the Proxy page, make sure no other VPN app is running, and check that you haven't excluded the app you're using in per-app proxy.
  :::

  :::accordion-item{label="How is it different from Clash for Android?"}
  CMFA is the successor to Clash for Android. It looks and works the same, but uses the actively maintained Mihomo core with support for more protocols. Your existing subscription link imports as is.
  :::
::
