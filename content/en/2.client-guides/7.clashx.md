ClashX is a Clash client that lives in the macOS menu bar and was known for being light and native. In November 2023, its developer deleted the official repository. Both ClashX and the paid ClashX Pro are no longer updated.

::warning
**ClashX is no longer maintained, and this site no longer offers it for download.** Its official channels are gone, so every installer still circulating is a third-party re-upload. ClashX Pro is also closed source, so there's no way to confirm those files haven't been tampered with. Mac users should switch to the open-source, actively maintained [Clash Verge Rev](/en/client-guides/clash-verge).
::

| Item | Status |
| --- | --- |
| Platform | macOS |
| Source | ClashX was open source and ClashX Pro was closed source; both repositories were deleted |
| Modern protocols | No VLESS, Hysteria2, etc. |
| Recommended replacement | [Clash Verge Rev](/en/client-guides/clash-verge) (Apple silicon and Intel) |

## Migrate to Clash Verge Rev

::steps
### Install Clash Verge Rev

Follow the [Clash Verge Rev guide](/en/client-guides/clash-verge) to download the Mac version: `aarch64.dmg` for Apple silicon, `x64.dmg` for Intel.

### Quit ClashX

Click the ClashX icon in the menu bar, uncheck **Set as system proxy**, and choose **Quit**.

### Import the same subscription

A subscription link works in any Clash client. Paste your existing link into **Profiles** in Clash Verge Rev, import it, and turn on the system proxy.
::

## For existing users

If you're still using an installed copy of ClashX for now, here are the basics.

::steps
### Add a remote config

Click the ClashX icon in the menu bar and choose **Config → Remote config → Manage**.

![Open remote config management from the ClashX menu bar](/images/clashx/install2.webp)

In the window that opens, click **Add**, enter the subscription link (Url) and a name (Config Name), and click **OK**.

![Add a remote config in ClashX](/images/clashx/install3.webp)

### Set as system proxy

Click the menu bar icon again, make sure the config you just added is selected, and check **Set as system proxy**.

![Set ClashX as the system proxy](/images/clashx/install4.webp)
::

## FAQ

::accordion
  :::accordion-item{label="Updating the remote config fails."}
  If the subscription contains servers using newer protocols such as VLESS or Hysteria2, the old ClashX core can't parse them and the update fails. The only fix is to switch to a newer client such as [Clash Verge Rev](/en/client-guides/clash-verge).
  :::

  :::accordion-item{label="ClashX won't open on a newer version of macOS."}
  ClashX hasn't been updated for new macOS releases in a long time, and compatibility problems won't be fixed. Migrate to Clash Verge Rev.
  :::

  :::accordion-item{label="System proxy is checked, but I still can't get online."}
  Switch to another server from the proxy list in the menu bar and make sure the outbound mode is Rule. If it still doesn't work, see [Troubleshooting](/en/installation-guide/troubleshooting).
  :::
::
