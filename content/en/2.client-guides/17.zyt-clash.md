HarmonyOS NEXT can't install Android APKs directly. Besides sideloading the native [Clash Box](/en/client-guides/clash-box) client, you can run an Android Clash client through **ZhuoYiTong (卓易通)**. This method needs no computer and no signing certificate, and works almost the same as on an Android phone.

::note
ZhuoYiTong is an Android app compatibility tool available in Huawei AppGallery that installs and runs Android apps on HarmonyOS NEXT. HarmonyOS 4 and earlier can still install APKs directly, so you don't need ZhuoYiTong there. Just follow the [Clash Meta for Android guide](/en/client-guides/clash-meta-for-android).
::

## Comparing the two methods

| | ZhuoYiTong + Android client | Clash Box sideload |
| --- | --- | --- |
| Difficulty | Easy, done entirely on the phone | Requires signing on a computer |
| Validity | Works long term | Self-signed apps expire after 14 days by default |
| Client choice | Clash Meta for Android, FlClash, and more | Clash Box only |
| How it runs | Inside a compatibility environment | Natively on HarmonyOS |

## Download

We recommend these open-source clients in ZhuoYiTong, both downloaded from their official GitHub pages:

| Client | Recommended file | Notes |
| --- | --- | --- |
| [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid/releases/latest){target="_blank"} | `meta-arm64-v8a-release.apk` | Recommended; active community, good compatibility |
| [FlClash](https://github.com/chen08209/FlClash/releases/latest){target="_blank"} | `android-arm64-v8a.apk` | Clean interface, same as the desktop app |

## Install

::steps
### Install ZhuoYiTong

Open Huawei AppGallery, search for **卓易通 (ZhuoYiTong)**, and install it. Follow the setup prompts on first launch and grant the permissions it asks for.

### Download the client APK

Open the GitHub link above in your phone's browser, download the matching `.apk`, and save it to local storage.

### Install it in ZhuoYiTong

Open ZhuoYiTong, choose to install a local app, select the `.apk` you downloaded, and install it. You can then open the Clash client from inside ZhuoYiTong.
::

## Setup

The steps below use Clash Meta for Android. The interface is identical to the one on an Android phone.

::steps
### Get your subscription link

Clash clients don't include any servers. Sign in to your provider's dashboard and copy your subscription link.

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Import from URL

Tap **Profiles** → **+** in the top-right corner → **URL**, paste the subscription link, tap the save icon in the top-right corner, and select the profile.

:::div{.grid.gap-4.grid-cols-2.sm:grid-cols-3}

![Choose Import from URL in CMFA](/images/clash-meta-for-android/copy-install3.png)

:::

### Start the proxy

Go back to the home screen, tap **Stopped** to start, and allow the VPN permission request. When the button changes to **Running**, you're connected.

## FAQ

::accordion
  :::accordion-item{label="Installing the APK in ZhuoYiTong fails."}
  Download the APK again to make sure it's complete, check that your phone has enough free storage, and update ZhuoYiTong to the latest version. If one client still won't install, try the other.
  :::

  :::accordion-item{label="The client shows Running, but I can't get online."}
  Make sure ZhuoYiTong has network permission, switch to a server that passes the latency test on the Proxy page, and check whether your subscription has expired. If it still doesn't work, restart ZhuoYiTong and the client, or see [Troubleshooting](/en/installation-guide/troubleshooting).
  :::

  :::accordion-item{label="Should I use ZhuoYiTong or Clash Box?"}
  Choose ZhuoYiTong if you want the easy route; it takes a few minutes. Choose [Clash Box](/en/client-guides/clash-box) if you want a native app and don't mind re-signing it regularly.
  :::
::
