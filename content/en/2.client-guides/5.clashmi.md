Clash Mi is an open-source client built with Flutter and powered by the Mihomo (Clash Meta) core. It's small, starts quickly, and uses the same interface on phones and computers. iPhone users can download it free from the App Store.

| Platforms | Core | License | Price |
| --- | --- | --- | --- |
| Windows · macOS · Linux · Android · iOS | Mihomo | GPL-3.0 | Free |

## Download

The desktop and Android versions are published on the official GitHub releases page, and the iOS version is on the App Store. On GitHub, pick the right file from the **Assets** list of the latest release:

| Device | File name contains | Notes |
| --- | --- | --- |
| Windows PC | `windows_x64.exe` | Installer; `windows_x64.zip` is the portable version |
| Mac | `macos_universal.dmg` | Works on Apple silicon and Intel |
| Linux | `linux_amd64.AppImage` / `.deb` / `.rpm` | Pick by distribution |
| Android phone | `android_arm64-v8a.apk` | For almost all Android phones |
| Older Android phone | `android_armeabi-v7a.apk` | Older 32-bit devices |

::callout{icon="i-simple-icons-github" to="https://github.com/KaringX/clashmi/releases/latest" target="_blank"}
**Download Clash Mi from GitHub**: the official releases page for desktop and Android.
::

::callout{icon="i-simple-icons-apple" to="https://apps.apple.com/app/clash-mi/id6744321968" target="_blank"}
**Get Clash Mi on the App Store**: the free iPhone and iPad app. It isn't available in the mainland China App Store. To try new versions early, join the official [TestFlight beta](https://testflight.apple.com/join/bjHXktB3){target="_blank"}.
::

::tip
Requirements: iOS 15, macOS 12, Android 8, Windows 10, or later.
::

## Install

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  Double-click the `.exe` and follow the installer. If you see "Windows protected your PC", click **More info → Run anyway**.
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  Open the `.dmg` and drag Clash Mi into **Applications**. If macOS blocks it on first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**.
  :::

  :::tabs-item{label="Android" icon="i-simple-icons-android"}
  Tap the downloaded `.apk` and allow installs from unknown sources when prompted.
  :::

  :::tabs-item{label="iOS" icon="i-lucide-smartphone"}
  Sign in to the App Store with an Apple ID from a region outside mainland China, then install from the link above.
  :::
::

## Setup

::steps
### Copy your subscription link

Clash Mi is only a client and does not include any servers. Sign in to your provider's dashboard and copy your subscription link.

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Add a profile link

On the home screen, tap **+** next to **My Profiles** and choose to add a profile link. Paste the subscription link, give it any name (for example, "My subscription"), and tap **✓** in the top-right corner to save.

:::div{.grid.gap-4.sm:grid-cols-3}
![Tap the plus button next to My Profiles in Clash Mi](/images/clashmi/add-config-1.webp)

![Choose to add a profile link in Clash Mi](/images/clashmi/add-config-2.webp)

![Paste the subscription link and save in Clash Mi](/images/clashmi/add-config-3.webp)
:::

### Connect

Go back to the home screen and turn on the switch at the top. When the status shows "Connected", you're done. The first time, your phone asks to add a VPN configuration and your computer asks for system proxy permission. Tap **Allow**. Keep the proxy mode on **Rule**.

![Clash Mi connected](/images/clashmi/app-start.webp)

### Choose a server

Tap **Proxies** on the home screen and choose automatic selection, or pick a low-latency server in the server group.

:::div{.grid.gap-4.sm:grid-cols-2}
![Choose automatic selection in Clash Mi](/images/clashmi/node-select-1.webp)

![Server groups in Clash Mi](/images/clashmi/node-select-2.webp)
:::
::

## FAQ

::accordion
  :::accordion-item{label="I can't connect, or every server times out."}
  Check whether your subscription has expired, update it under **My Profiles**, and make sure your device's clock is correct. On Windows, run Clash Mi as administrator when using TUN mode. See [Troubleshooting](/en/installation-guide/troubleshooting) for more.
  :::

  :::accordion-item{label="I can't find Clash Mi on the App Store."}
  It isn't listed in the mainland China App Store. Switch to an Apple ID from another region, or open the App Store link on this page.
  :::

  :::accordion-item{label="How do I update my subscription?"}
  Tap **My Profiles** on the home screen and update the subscription there. You can also set an auto-update interval when adding the profile.
  :::
::
