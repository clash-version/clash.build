Clash Verge Rev is an open-source desktop client built with Tauri and powered by the Mihomo (Clash Meta) core. After the original Clash Verge was discontinued, the community took over development. It has a clean interface, frequent updates, and is our top recommendation for desktop users.

| --- | --- | --- | --- |
| Windows · macOS · Linux | Mihomo | GPL-3.0 | Free |

![Clash Verge Rev main window](/images/clash-verge-rev/preview-1.webp)

## Download

Clash Verge Rev is published only on its official GitHub releases page. Open the page and pick the right file from the **Assets** list of the latest release:

| Device | File name contains | Notes |
| --- | --- | --- |
| Windows PC | `x64-setup.exe` | For almost all Intel and AMD PCs |
| Windows on ARM | `arm64-setup.exe` | Snapdragon and other ARM-based Windows devices |
| Mac (Apple silicon) | `aarch64.dmg` | M1, M2, M3, M4, and later |
| Mac (Intel) | `x64.dmg` | Macs with Intel processors |
| Linux | `amd64.deb` / `x86_64.rpm` | deb for Debian/Ubuntu, rpm for Fedora/openSUSE |

::callout{icon="i-simple-icons-github" to="https://github.com/clash-verge-rev/clash-verge-rev/releases/latest" target="_blank"}
**Download Clash Verge Rev from GitHub**: the official releases page, always the latest version.
::

::tip
Not sure which chip you have? On Windows, open **Settings → System → About** and check **System type**. On a Mac, open the Apple menu → **About This Mac** and check **Chip**. Only download from the official releases page, never from unknown file-sharing links.
::

## Install

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  Double-click the `setup.exe` file and follow the installer. If you see "Windows protected your PC", click **More info → Run anyway**.
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  Open the `.dmg` and drag Clash Verge into **Applications**. If macOS says the developer cannot be verified, go to **System Settings → Privacy & Security** and click **Open Anyway**.
  :::

  :::tabs-item{label="Linux" icon="i-simple-icons-linux"}
  Run the matching command in your download folder:

  ```bash
  # Debian / Ubuntu
  sudo apt install ./Clash.Verge_*_amd64.deb

  # Fedora / openSUSE
  sudo dnf install ./Clash.Verge-*.x86_64.rpm
  ```
  :::
::

## Setup

::steps
### Get your subscription link

Clash Verge Rev is only a client and does not include any servers. Sign in to your provider's dashboard and copy your subscription link (usually under "Subscribe" or "Copy subscription URL").

![Copy the subscription link from your provider's dashboard](/images/copy-sub.webp)

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Import the subscription

Click **Profiles** in the sidebar, paste the link into the input box at the top, and click **Import**.

![Paste the subscription link in Clash Verge Rev and click Import](/images/clash-verge-rev/add-config-1.webp)

When a profile card appears with data usage and update time, the import worked.

![Subscription imported successfully in Clash Verge Rev](/images/clash-verge-rev/add-config-2.webp)

### Turn on the system proxy

Go back to **Home**. Under network settings, choose **System Proxy**, then turn on the **System Proxy** switch. Keep the proxy mode on **Rule**.

![Turn on the system proxy in Clash Verge Rev](/images/clash-verge-rev/app-start.webp)

### Choose a server

Open **Proxies** and click the latency test icon. Select **Auto** (automatic selection) or pick a server with low latency. If your usual websites load in the browser, you're done.

![Test latency and choose a server in Clash Verge Rev](/images/clash-verge-rev/node-test.webp)
::

## Advanced settings

### TUN mode (virtual network adapter)

The system proxy only covers apps that respect system proxy settings. Games, terminals, and other apps that ignore it need TUN mode, which captures all traffic.

On **Home**, switch the network setting to **TUN mode** and turn it on. On Windows, install the service mode or run the app as administrator when prompted.

![Enable TUN mode in Clash Verge Rev](/images/clash-verge-rev/open-tun.webp)

::warning
Use either the system proxy or TUN mode, not both. If you lose your connection after enabling TUN, turn it off first and then troubleshoot. See [Advanced Settings](/en/installation-guide/advanced-settings) for details.
::

### Enable IPv6

Go to **Settings → Clash Settings** and turn on **IPv6**.

![Enable IPv6 in Clash Verge Rev](/images/clash-verge-rev/open-ipv6.webp)

Your local network must support IPv6. Check at [test-ipv6.com](https://test-ipv6.com/){target="_blank"}: IPv6 works only if the page shows an IPv6 address. If the test fails, your ISP or router probably doesn't provide IPv6, so leave it off.

### Update the subscription

When your provider changes servers, open **Profiles** and click the refresh button on the profile card.

![Update a subscription in Clash Verge Rev](/images/clash-verge-rev/update-config-1.webp)

### Check AI and streaming access

The **Test** page checks whether ChatGPT, Claude, Netflix, and other services work through the current server. Run it again after switching servers.

![Check AI and streaming access in Clash Verge Rev](/images/clash-verge-rev/media_test.webp)

## FAQ

::accordion
  :::accordion-item{label="The subscription import fails. What should I do?"}
  Make sure the link was copied completely with no extra spaces and that the subscription hasn't expired. Check that your computer is online, then import again. If it still fails, see [Troubleshooting](/en/installation-guide/troubleshooting).
  :::

  :::accordion-item{label="The proxy is on, but websites still don't load."}
  Check that the System Proxy switch is on, the current server passes the latency test, and the mode is set to Rule. If your browser has another proxy extension, disable it and try again.
  :::

  :::accordion-item{label="macOS says the app “is damaged and can’t be opened”."}
  This is macOS blocking an unnotarized app; the file isn't actually damaged. Open Terminal, run the command below, and open the app again:

  ```bash
  sudo xattr -r -c "/Applications/Clash Verge.app"
  ```
  :::

  :::accordion-item{label="How do I update to a new version?"}
  The app prompts you when an update is available. You can also download the latest installer from the official releases page and install over the old version. Your subscriptions and settings are kept.
  :::
::
