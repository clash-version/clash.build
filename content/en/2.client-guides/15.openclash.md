OpenClash is an open-source Clash plugin for OpenWrt routers with a LuCI web interface. Once it's running on your router, every phone, computer, and TV connected to it can use the proxy without installing a client on each device.

| Runs on | Core | License | Price |
| --- | --- | --- | --- |
| OpenWrt (LuCI 19.07 or later) | Mihomo | MIT | Free |

::note
OpenClash is for people who already run OpenWrt and are comfortable with the router admin panel. If you only need the proxy on one or two devices, installing a client such as [Clash Verge Rev](/en/client-guides/clash-verge) is much simpler.
::

## Download

OpenClash is published on its official GitHub releases page. Pick the package for your router's package manager:

| Package manager | File name | For |
| --- | --- | --- |
| opkg | `luci-app-openclash_*_all.ipk` | Most current OpenWrt versions |
| apk | `luci-app-openclash-*.apk` | Newer OpenWrt versions that use the apk package manager |

::callout{icon="i-simple-icons-github" to="https://github.com/vernesong/OpenClash/releases/latest" target="_blank"}
**Download OpenClash from GitHub**: the official releases page, always the latest version.
::

::tip
Not sure which package manager you have? SSH into the router and run `which opkg apk`. Whichever one prints a path is the one your system uses.
::

## Install

::steps
### Install dependencies

SSH into the router and install the dependencies for your firewall type. OpenWrt 22.03 and later use nftables (Firewall4) by default; earlier versions use iptables.

:::code-group
```bash [opkg · nftables]
opkg update
opkg install bash dnsmasq-full curl ca-bundle ip-full ruby ruby-yaml kmod-tun kmod-inet-diag unzip kmod-nft-tproxy luci-compat luci luci-base
```

```bash [opkg · iptables]
opkg update
opkg install bash iptables dnsmasq-full curl ca-bundle ipset ip-full iptables-mod-tproxy iptables-mod-extra ruby ruby-yaml kmod-tun kmod-inet-diag unzip luci-compat luci luci-base
```

```bash [apk · nftables]
apk update
apk add bash dnsmasq-full curl ca-bundle ip-full ruby ruby-yaml kmod-tun kmod-inet-diag unzip kmod-nft-tproxy luci-compat luci luci-base
```
:::

If you get a conflict between `dnsmasq` and `dnsmasq-full`, run `opkg remove dnsmasq` (or `apk del dnsmasq` on apk systems) first, then install the dependencies again.

### Install OpenClash

**From the web interface**: in LuCI, open **System → Software**, click **Upload Package**, choose the package you downloaded, and install it. Refresh the page and **OpenClash** appears under the **Services** menu.

![Install OpenClash from the OpenWrt software page](/images/openclash/install1.webp)

**From the command line**: upload the package to the router's `/tmp` directory and run:

:::code-group
```bash [opkg]
opkg install /tmp/luci-app-openclash_*_all.ipk
```

```bash [apk]
apk add -q --force-overwrite --clean-protected --allow-untrusted /tmp/luci-app-openclash-*.apk
```
:::
::

## Setup

::steps
### Get your subscription link

OpenClash is only a proxy tool and does not include any servers. Sign in to your provider's dashboard and copy your subscription link.

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Add the subscription

Open **Services → OpenClash**, go to **Config Subscribe**, click **Add**, enter a name and the subscription URL, save, and then click **Update Config** to download it.

### Start OpenClash

Go back to the **Running Status** page, make sure the config file is enabled, and click **Start OpenClash** at the bottom. The first start downloads the core automatically, so the router needs to reach GitHub. Give it a moment.

![OpenClash Running Status page: paste a subscription and start](/images/openclash/install2.webp)

### Verify

Once it starts, the Running Status page shows each service as running. Open your usual websites on a phone or computer connected to the router. If they load, you're done.
::

## FAQ

::accordion
  :::accordion-item{label="It gets stuck downloading the core on first start."}
  The first start downloads the core from GitHub. If the router can't reach GitHub quickly, download the core for your router's architecture from Mihomo's official GitHub on your computer, then upload it manually with OpenClash's file upload feature.
  :::

  :::accordion-item{label="My whole network went down after starting it."}
  Click **Stop OpenClash** on the Running Status page to restore the network. Then check that the subscription is valid and that all dependencies are installed, especially `dnsmasq-full` and the firewall packages. See [Troubleshooting](/en/installation-guide/troubleshooting) for more.
  :::

  :::accordion-item{label="Can I proxy only some devices?"}
  Yes. In OpenClash's **Plugin Settings**, set up LAN access control to choose which devices use or bypass the proxy by IP or MAC address.
  :::
