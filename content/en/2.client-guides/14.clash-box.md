Clash Box is a native Clash client for **HarmonyOS NEXT**, powered by the Mihomo (Clash Meta) core. It supports Shadowsocks, VMess, VLESS, Trojan, Hysteria2, and other mainstream protocols. Most of the project's code is open source.

| HarmonyOS NEXT | Mihomo | GPL-3.0 (most code open source) | Free |

![Clash Box for HarmonyOS](/images/clash-box/install1.webp)

::tip
**Check your system version first.** HarmonyOS 4 and earlier can still install Android apps, so [Clash Meta for Android](/en/client-guides/clash-meta-for-android) is simpler. On HarmonyOS NEXT, if you'd rather not sideload, use [ZhuoYiTong to install Clash](/en/client-guides/zyt-clash).
::

## Download

Clash Box is published on its official GitHub releases page as an unsigned `.hap` file (the file name contains `unsigned.hap`). You need to sign it yourself and sideload it.

::callout{icon="i-simple-icons-github" to="https://github.com/xiaobaigroup/ClashBox/releases/latest" target="_blank"}
**Download Clash Box from GitHub**: the official releases page, always the latest version.
::

## Sideloading

Clash Box isn't listed in Huawei AppGallery for mainland China. If you can find it in your region's AppGallery, install it from there. Otherwise, use a computer to sign the `.hap` and sideload it onto your phone. The project recommends **Auto-installer** or **DevEco Testing** for signing and installing; follow each tool's own instructions.

::warning
- **Signing needs a mainland China IP**: Huawei's signing server rejects requests from outside mainland China. If you're signing from abroad, switch to a mainland China network first.
- **Certificate validity**: self-signed apps are valid for **14 days** by default, or **180 days** after developer identity verification. When the certificate expires, sign and install again.
::

## Setup

::steps
### Get your subscription link

Clash Box is only a client and does not include any servers. Sign in to your provider's dashboard and copy your subscription link.

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Add a profile

Open Clash Box, tap the **Profiles** tab at the bottom, tap **+** in the bottom-right corner, paste the subscription link, and save.

### Start the proxy

Go back to **Home**, set the routing mode to **Rule**, and tap the button in the bottom-right corner to start. Allow the VPN permission request the first time. When the button starts a timer, you're connected.

## FAQ

::accordion
  :::accordion-item{label="Installation fails with a signing error."}
  Make sure your computer is on a mainland China network and that developer mode and USB debugging are enabled on your phone. If it still fails, use [ZhuoYiTong](/en/client-guides/zyt-clash) to install an Android client instead.
  :::

  :::accordion-item{label="The app stopped opening after two weeks."}
  The self-signed certificate expired (14 days by default). Sign and install again. After developer identity verification, the validity extends to 180 days.
  :::

  :::accordion-item{label="I can't get online after starting."}
  Switch to another server on the Proxies page, make sure the routing mode is Rule, and check whether your subscription has expired. See [Troubleshooting](/en/installation-guide/troubleshooting) for more.
  :::
::
