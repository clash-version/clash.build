Clash for Android (CFA) is the classic Android Clash client created by the developer Kr328. In November 2023, the project was discontinued and its official repository was deleted.

::warning
**Clash for Android is no longer maintained, and this site no longer offers it for download.** Its official channels are gone, so every installer still circulating is a third-party re-upload that may have been tampered with. Use its open-source successor, [Clash Meta for Android](/en/client-guides/clash-meta-for-android), which looks and works almost exactly the same.
::

| Item | Status |
| --- | --- |
| Last version | 2.5.12 |
| Source | Was open source; official repository deleted |
| Modern protocols | No VLESS, Hysteria2, TUIC, etc. |
| Recommended replacement | [Clash Meta for Android](/en/client-guides/clash-meta-for-android) |

## Migrate to Clash Meta for Android

::steps
### Install Clash Meta for Android

Download and install it from the official GitHub page by following the [Clash Meta for Android guide](/en/client-guides/clash-meta-for-android). Both apps can be installed side by side.

### Stop Clash for Android

Tap **Running** on the CFA home screen to stop it, so two VPNs don't run at the same time.

### Import the same subscription

In CMFA, import your existing subscription link through **Profiles → + → URL**, select it, and start the proxy. Once everything works, you can uninstall CFA.
::

## For existing users

If you're still using an installed copy of CFA for now, here are the basics. The interface is the same as CMFA.

::steps
### Import a subscription

Open CFA and tap **Profiles** → **+** in the top-right corner → **URL**. Paste the subscription link, save, and select the profile.

:::div{.grid.gap-4.grid-cols-2}

![Tap the plus button to add a profile in Clash for Android](/images/clash-meta-for-android/copy-install2.png)

### Start the proxy

Go back to the home screen and tap **Stopped** to start. Allow the VPN permission request the first time.

## FAQ

::accordion
  :::accordion-item{label="The subscription imports, but no server connects."}
  If your provider uses newer protocols such as VLESS or Hysteria2, CFA can't read those servers. CFA can't be upgraded, so switch to [Clash Meta for Android](/en/client-guides/clash-meta-for-android).
  :::

  :::accordion-item{label="Installing on a new phone fails with a parsing error."}
  CFA hasn't been updated for newer Android versions in a long time, and some new phones can't install it. Use Clash Meta for Android instead.
  :::

  :::accordion-item{label="Does it work on Huawei HarmonyOS phones?"}
  HarmonyOS 4 and earlier can install Android apps, but Clash Meta for Android is still the better choice. For HarmonyOS NEXT, see [Clash Box](/en/client-guides/clash-box).
  :::
::
