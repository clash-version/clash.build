Hiddify is an open-source proxy client for every major platform, built on the sing-box core. It reads Clash / Mihomo, sing-box, and V2Ray subscriptions directly. The Android app is simple: copy your subscription and connect in one tap. This guide covers Android; for desktop, see the [Hiddify guide](/en/client-guides/hiddify).

| --- | --- | --- | --- |
| Android | sing-box | GPL-3.0 | Free |

## Download

Hiddify for Android is published on its official GitHub releases page. Open the page and pick the right file from the **Assets** list of the latest release:

| Device | File name | Notes |
| --- | --- | --- |
| Not sure | `Hiddify-Android-universal.apk` | Universal build for any device; recommended |
| Most Android phones | `Hiddify-Android-arm64.apk` | Smaller download |
| Older Android phones | `Hiddify-Android-arm7.apk` | Older 32-bit devices |

::callout{icon="i-simple-icons-github" to="https://github.com/hiddify/hiddify-app/releases/latest" target="_blank"}
**Download Hiddify from GitHub**: the official releases page, always the latest version.
::

## Setup

::steps
### Install the app

Tap the downloaded `.apk` to install it. If Android blocks apps from unknown sources, allow your browser or file manager to install apps when prompted.

### Copy your subscription link

Hiddify is only a client and does not include any servers. Sign in to your provider's dashboard and copy your subscription link.

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Add from clipboard

Open Hiddify, tap **New Profile**, and choose **Add from clipboard**. You can also use **Scan QR code** if your provider shows a subscription QR code.

### Connect

Go back to the home screen and tap the button in the middle. The first time, Android asks for VPN permission. Tap **OK**. When it shows "Connected", you're done.

## Advanced settings

### Service mode and TUN

On Android, Hiddify runs in **VPN** service mode by default, which already routes all of the phone's traffic, so you usually don't need to change anything. To adjust it, open the menu in the top-left corner and go to **Config Options**, where you can change the service mode, TUN implementation, IPv6, and DNS. Leave unfamiliar options at their defaults.

## FAQ

::accordion
  :::accordion-item{label="Adding from the clipboard says the link is invalid."}
  Make sure the clipboard contains the full subscription link starting with `https://`, with no extra text or spaces. You can also choose manual entry and paste the link.
  :::

  :::accordion-item{label="It says Connected, but websites don't load."}
  Switch to a server with lower latency on the Proxies page, make sure the subscription hasn't expired, and update it once from the home screen. See [Troubleshooting](/en/installation-guide/troubleshooting) for more.
  :::

  :::accordion-item{label="The connection drops soon after connecting."}
  Some phones close VPN apps in the background. In your phone's settings, allow Hiddify to run in the background and turn off battery optimization for it.
  :::
::
