[clashctl](https://github.com/nelvko/clashctl){target="_blank"} (formerly clash-for-linux-install) is an open-source set of command-line scripts for Linux. It deploys the Mihomo core in one step and adds subscription management, a terminal proxy switch, TUN mode, and a web dashboard. It's ideal for headless servers and for desktop users who prefer the command line.

| Runs on | Core | License | Price |
| --- | --- | --- | --- |
| Mainstream Linux distributions and containers | Mihomo (default) / Clash | MIT | Free |

::tip
On a Linux desktop with a graphical interface, you can also install [Clash Verge Rev](/en/client-guides/clash-verge) or [FlClash](/en/client-guides/flclash).
::

## Install

::steps
### Check dependencies

The installer needs `curl`, `tar`, `gzip`, `unzip`, and `sha256sum`. Install any that are missing:

:::code-group
```bash [Debian / Ubuntu]
sudo apt update && sudo apt install -y curl tar gzip unzip coreutils
```

```bash [CentOS / Rocky / Fedora]
sudo dnf install -y curl tar gzip unzip coreutils
```

```bash [Arch]
sudo pacman -S --needed curl tar gzip unzip coreutils
```
:::

### Run the installer

```bash
curl -fsSL https://raw.githubusercontent.com/nelvko/clashctl/HEAD/install.sh | bash
```

The script downloads the project, deploys the core, and registers the `clashctl` command. Both regular users and root can install it, and it supports systemd and OpenRC. Open a new terminal afterwards so the command is available.

:::tip
You can pass your subscription during installation:

```bash
curl -fsSL https://raw.githubusercontent.com/nelvko/clashctl/HEAD/install.sh | bash -s -- --sub "<subscription link>"
```

If your server reaches GitHub slowly, use `--gh-proxy <address>` to set a GitHub mirror you trust.
:::
::

## Setup

::steps
### Get your subscription link

clashctl is only a management tool and does not include any servers. Sign in to your provider's dashboard and copy your subscription link.

:::note
Need a subscription? See [these subscription plans](https://iv.coolgo.me/aff.php?aff=35){target="_blank"} (third-party affiliate link; check the details before you buy). Treat your subscription link like a password and don't share it.
:::

### Add the subscription

```bash
clashctl sub add --use "<subscription link>"
```

Subscription links contain special characters such as `&`, so always wrap them in double quotes. `--use` activates the subscription right after adding it.

### Turn on the proxy

```bash
clashctl on
curl -I https://www.google.com
```

`clashctl on` starts the core automatically and sets the proxy environment variables for the **current terminal**. If the second command returns an HTTP status code, the proxy works.
::

## Common commands

| Command | What it does |
| --- | --- |
| `clashctl on` / `clashctl off` | Turn the proxy on / off for the current terminal (`off` keeps the core running by default) |
| `clashctl start` / `clashctl stop` | Start / stop only the core |
| `clashctl status` | Show core status, terminal proxy status, and proxy addresses |
| `clashctl sub ls` | List subscriptions |
| `clashctl sub use <name>` | Switch subscriptions |
| `clashctl sub update` | Update the current subscription (`--all` updates all of them) |
| `clashctl node` | Switch servers |
| `clashctl log` | View logs |
| `clashctl upgrade` | Upgrade the core |
| `clashctl update` | Update the clashctl scripts |

## Advanced settings

### Web dashboard

```bash
clashctl ui                  # print the dashboard address
clashctl secret              # show the access secret
clashctl secret "<new secret>"   # change the secret
```

Open the dashboard address in a browser to switch servers and view connections. Don't expose a server's dashboard directly to the internet; use SSH port forwarding instead.

### TUN mode

```bash
clashctl tun on      # enable
clashctl tun off     # disable
clashctl tun         # show status
```

TUN mode captures all system traffic, including Docker containers, so you no longer depend on terminal environment variables. Some minimal kernels and container environments don't support TUN. See [Advanced Settings](/en/installation-guide/advanced-settings) for background.

### Mixin custom config

Mixin is merged with your subscription config and takes priority, which makes it the place for custom rules, DNS, and proxy groups:

```bash
clashctl mixin       # view the Mixin config
clashctl mixin -e    # edit Mixin; changes apply on save
clashctl mixin -c    # view the original subscription config
clashctl mixin -r    # view the config the core is actually running
```

### Uninstall

```bash
clashctl off
bash "$CLASHCTL_HOME/uninstall.sh"
```

Run `clashctl off` first to clear the proxy variables in the current terminal; the uninstall script can't do this. Uninstalling deletes the install directory and its data, so back up any configs you want to keep.

## FAQ

::accordion
  :::accordion-item{label="Adding the subscription fails."}
  Make sure the link is wrapped in double quotes and the subscription hasn't expired. If the format isn't compatible, fetch it again with the local converter: `clashctl sub update --convert`.
  :::

  :::accordion-item{label="Still no connection after clashctl on."}
  Check in order: `clashctl status` to confirm the core is running; `clashctl log` for errors; `echo $http_proxy` to confirm the current terminal has the proxy variables; and whether the subscription has working servers. The variables only apply to the terminal where you ran `clashctl on`, so run it again in new terminals.
  :::

  :::accordion-item{label="The proxy port differs from the one in the guide."}
  The actual port depends on your environment, for example when the default port is already in use. Use the proxy address shown by `clashctl status`.
  :::

  :::accordion-item{label="The web dashboard won't open."}
  Make sure the core is running and your firewall allows the dashboard port. For a remote server, use the server's IP address or forward the port to your computer over SSH.
  :::
::
