客户端安装完成后，需要导入配置才能显示节点和规则。最常见的方式是添加服务提供方生成的订阅链接。

::warning
订阅链接通常包含你的访问凭据。不要将链接发布到截图、论坛、群聊或公开代码仓库中。如果怀疑链接已经泄露，请立即在服务提供方后台重置。
::

## 通过订阅链接导入

以下步骤以 Clash Verge Rev 为例。

::steps
### 复制订阅地址 

[前往购买](https://iv.coolgo.me/aff.php?aff=35)

登录你的服务提供方后台，找到“订阅地址”“一键订阅”或类似入口，复制适用于 Clash 或 Mihomo 的链接。

订阅地址通常以 `https://` 开头。不要复制网页地址、邀请链接或二维码图片地址。

### 打开配置页面

在客户端中进入“订阅”或“配置”页面，将复制的链接粘贴到顶部输入框。

![在 Clash Verge Rev 中粘贴订阅链接](/images/clash-verge-rev/add-config-1.webp)

### 下载配置

点击“导入”“下载”或右侧的添加按钮。客户端会请求订阅内容，并在成功后生成一个新的配置卡片。

![Clash Verge Rev 成功添加订阅配置](/images/clash-verge-rev/add-config-2.webp)

### 设为当前配置

确认新配置已经被选中。部分客户端会自动切换，部分客户端需要点击配置卡片或“使用”按钮。
::

## 导入本地配置文件

如果你拿到的是 `.yaml` 或 `.yml` 文件，可以在配置页面选择“导入文件”或将文件拖入客户端。

导入后请检查：

- 配置名称是否出现在列表中。
- 配置是否已经切换为启用状态。
- “代理”页面是否能看到策略组和节点。
- 客户端日志中是否出现格式错误。

## 更新订阅

订阅中的节点、规则和剩余流量可能发生变化，建议使用客户端提供的更新按钮，而不是反复删除并重新添加链接。

![在 Clash Verge Rev 中更新当前订阅](/images/clash-verge-rev/update-config-1.webp)

::tip
如果服务提供方要求定期更新，可以启用自动更新，但不建议设置过短的更新间隔，以免频繁请求导致订阅地址被限制。
::

## 导入失败怎么办

| 现象 | 优先检查 |
| --- | --- |
| 提示 URL 无效 | 是否复制了完整的 `https://` 链接 |
| 下载超时 | 当前网络是否能访问订阅服务器 |
| 返回 401 或 403 | 订阅是否过期、失效或被重置 |
| 配置解析失败 | 链接是否输出 Clash/Mihomo 支持的格式 |
| 导入成功但没有节点 | 是否选中了刚添加的配置 |

仍然无法解决时，请继续查看[故障排查](/zh-CN/installation-guide/troubleshooting)。
