这条流程适合第一次使用 Clash 兼容客户端的用户。页面以 **Clash Verge Rev** 作为界面示例，其他客户端的按钮名称可能略有不同，但操作顺序基本一致。

::note
客户端只是读取配置并管理系统网络的工具，安装完成后还需要导入一份有效的订阅链接或本地配置文件。
::

## 开始前准备

- 一台 Windows、macOS、Linux、Android 或 iOS 设备。
- 与设备平台和处理器架构匹配的客户端安装包。
- 由你的服务提供方提供的订阅链接，或一份可用的 YAML 配置文件。

## 完整安装流程

::steps
### 选择并下载客户端

前往与当前设备对应的下载页面：

- [Windows 客户端](/zh-CN/download/windows)
- [macOS 客户端](/zh-CN/download/macos)
- [Linux 客户端](/zh-CN/download/linux)
- [Android 客户端](/zh-CN/download/android)
- [iPhone / iPad 客户端](/zh-CN/download/ios)

不确定时，优先使用平台页面中标记为“推荐”的客户端。

### 安装客户端

桌面系统通常使用 EXE、DMG、DEB、RPM 或 AppImage；Android 使用 APK；iPhone 和 iPad 通过 App Store 安装。

下载页面已经列出各平台的架构和安装格式说明。安装前请再次确认文件来源与设备架构。

### 导入配置

复制服务提供方给你的订阅地址，在客户端的“配置”“订阅”或“Profiles”页面粘贴并下载。

[查看配置导入步骤 →](/zh-CN/installation-guide/import-configuration)

### 选择节点

进入“代理”或“Proxies”页面。第一次使用时可以先选择“自动选择”，也可以测试延迟后手动选择节点。

[了解如何选择节点 →](/zh-CN/installation-guide/select-node)

### 开启系统代理

返回客户端首页，开启“系统代理”。保持规则模式，再打开浏览器检查连接是否正常。

[查看启动和验证方法 →](/zh-CN/installation-guide/enable-proxy)
::

## 完成后的状态

正常情况下，你应该能看到以下状态：

- 订阅配置已经下载，并显示最近更新时间。
- 代理页面能看到节点或策略组。
- 至少一个节点可以完成延迟测试。
- 系统代理开关已经开启。
- 浏览器可以正常访问目标网站。

::tip
如果节点全部超时，或开启代理后无法访问任何网站，请先关闭系统代理，再按照[故障排查清单](/zh-CN/installation-guide/troubleshooting)逐项检查。
::
