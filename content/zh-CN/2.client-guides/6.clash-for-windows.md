Clash for Windows（简称 CFW）曾是最流行的 Clash 桌面客户端。2023 年 11 月，作者停止开发并删除了官方仓库，此后再没有任何更新。

::warning
**Clash for Windows 已停止维护，本站不再提供下载。** CFW 本身不开源，官方渠道已经关闭，网上流传的安装包都来自第三方转存，无法确认是否被篡改。建议新用户直接使用开源且持续更新的 [Clash Verge Rev](/zh-CN/client-guides/clash-verge)。
::

| 项目 | 现状 |
| --- | --- |
| 最后版本 | 0.20.39 |
| 开源情况 | 闭源，官方仓库已删除 |
| 新协议支持 | 不支持 VLESS、Hysteria2、TUIC 等 |
| 推荐替代 | [Clash Verge Rev](/zh-CN/client-guides/clash-verge)（Windows / macOS / Linux） |

## 为什么建议迁移

- **没有安全更新**：停更后发现的问题都不会再修复。
- **协议过时**：内置的是旧版 Clash 内核，很多订阅里的新协议节点无法使用，甚至会导致整个配置导入失败。
- **替代品更好用**：Clash Verge Rev 的界面和使用方式与 CFW 相似，迁移几乎没有学习成本。

## 迁移到 Clash Verge Rev

::steps
### 安装 Clash Verge Rev

按照 [Clash Verge Rev 教程](/zh-CN/client-guides/clash-verge) 从官方 GitHub 下载并安装。

### 退出 Clash for Windows

在 CFW 中关闭 **System Proxy**，然后从系统托盘退出程序，避免两个客户端同时修改系统代理。

### 导入同一个订阅

订阅链接在任何 Clash 客户端中都通用。把原来在 CFW 中使用的订阅链接粘贴到 Clash Verge Rev 的 **订阅** 页面导入，再开启系统代理即可。
::

::tip
迁移完成并确认可以正常上网后，可以在系统设置中卸载 Clash for Windows。
::

## 老用户使用说明

如果你暂时还在使用已安装的 CFW，可以参考下面的基本操作。

::steps
### 导入订阅

点击左侧 **Profiles**，把订阅链接粘贴到顶部的「Download from a URL」输入框，点击 **Download**。

![Clash for Windows 在 Profiles 页面粘贴订阅并下载](/images/clash-for-windows/install1.webp)

列表中出现新的配置文件，并显示流量和到期时间，就说明导入成功，点击选中它。

![Clash for Windows 订阅导入成功](/images/clash-for-windows/install2.webp)

### 开启系统代理

点击左侧 **General**，打开 **System Proxy** 开关。

![Clash for Windows 在 General 页面开启系统代理](/images/clash-for-windows/install3.webp)
::

### TUN 模式与 IPv6

在 **General** 页面可以打开 **IPv6** 和 **TUN Mode** 开关。TUN 模式需要先点击 **Service Mode** 旁的 **Manage** 安装服务。

::div{.grid.gap-4.sm:grid-cols-2}
![Clash for Windows 开启 IPv6](/images/clash-for-windows/open-ipv6.webp)

![Clash for Windows 开启 TUN 模式](/images/clash-for-windows/open-tun.webp)
::

## 常见问题

::accordion
  :::accordion-item{label="下载订阅时报错，配置无法加载？"}
  这是 CFW 最常见的问题：订阅里包含 VLESS、Hysteria2 等新协议节点，旧内核无法识别，导致整个配置解析失败。CFW 已无法升级，唯一的解决办法是换用 [Clash Verge Rev](/zh-CN/client-guides/clash-verge) 等支持新协议的客户端。

  ![Clash for Windows 配置导入失败的报错提示](/images/clash-for-windows/node-pull-error.webp)
  :::

  :::accordion-item{label="Mac 上能用 Clash for Windows 吗？"}
  CFW 曾经提供 macOS 版本，但同样已经停更。Mac 用户请直接使用 [Clash Verge Rev](/zh-CN/client-guides/clash-verge)，它同时支持 Apple 芯片和 Intel 芯片。
  :::

  :::accordion-item{label="开启了 System Proxy 还是无法上网？"}
  先在 **Proxies** 页面换一个节点，并确认模式为 Rule。如果仍然不行，大概率是协议不兼容，建议直接迁移到新客户端。更多排查步骤见[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::
::
