FlClash 是基于 Flutter 开发的开源客户端，内置 Mihomo（Clash Meta）内核。它在电脑和安卓手机上使用同一套界面，适合同时在多台设备上使用 Clash 的用户。

| 支持平台 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| Windows · macOS · Linux · Android | Mihomo | GPL-3.0 | 免费 |

## 下载

FlClash 只在官方 GitHub 发布安装包。打开发布页后，在最新版本的 **Assets** 列表里按下表选择文件：

| 设备 | 文件名包含 | 说明 |
| --- | --- | --- |
| Windows 电脑 | `windows-amd64-setup.exe` | 安装版；`windows-amd64.zip` 为免安装版 |
| Mac（Apple 芯片） | `macos-arm64.dmg` | M1 及之后的 Mac |
| Mac（Intel 芯片） | `macos-amd64.dmg` | Intel 处理器的 Mac |
| Linux | `linux-amd64.deb` / `.rpm` / `.AppImage` | 按发行版选择，AppImage 通用 |
| 安卓手机 | `android-arm64-v8a.apk` | 绝大多数安卓手机选这个 |
| 老旧安卓手机 | `android-armeabi-v7a.apk` | 32 位老机型 |

::callout{icon="i-simple-icons-github" to="https://github.com/chen08209/FlClash/releases/latest" target="_blank"}
**前往 GitHub 下载 FlClash**：官方发布页，始终是最新版本。
::

::tip
`android-x86_64.apk` 只适用于模拟器和少数 x86 设备，普通手机安装会失败。请只从官方发布页下载，不要使用来路不明的网盘或群文件。
::

## 安装

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  双击 `setup.exe`，按提示完成安装。如果出现「Windows 已保护你的电脑」，点击 **更多信息 → 仍要运行**。
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  打开 `.dmg`，把 FlClash 拖进「应用程序」文件夹。首次打开如果被拦截，到 **系统设置 → 隐私与安全性** 点击 **仍要打开**。
  :::

  :::tabs-item{label="Linux" icon="i-simple-icons-linux"}
  ```bash
  # Debian / Ubuntu
  sudo apt install ./FlClash-*-linux-amd64.deb

  # Fedora / openSUSE
  sudo dnf install ./FlClash-*-linux-amd64.rpm
  ```
  :::

  :::tabs-item{label="Android" icon="i-simple-icons-android"}
  点击下载好的 `.apk` 安装。如果系统提示「禁止安装未知来源应用」，按提示允许当前浏览器或文件管理器安装即可。
  :::
::

## 使用教程

::steps
### 准备订阅链接

FlClash 只是客户端，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接（通常在「一键订阅」或「复制订阅地址」中）。

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 添加配置

点击左侧 **配置** 图标，再点右下角的 **+**。

![FlClash 进入配置页并点击添加](/images/flclash/install1.webp)

在弹出的菜单中选择 **URL**。

![FlClash 选择通过 URL 添加配置](/images/flclash/install2.webp)

粘贴订阅链接，点击 **提交**。

![FlClash 粘贴订阅链接并提交](/images/flclash/install3.webp)

配置列表出现订阅卡片并显示流量信息，就说明导入成功。

![FlClash 订阅导入成功](/images/flclash/install4.webp)

### 启动代理

回到 **仪表盘**，出站模式选择 **规则**，确认「系统代理」处于开启状态，然后点击右下角的 **▶** 按钮启动。安卓首次启动会请求 VPN 权限，点击 **允许**。

![FlClash 在仪表盘启动代理](/images/flclash/install6.webp)

### 选择节点

进入 **代理** 页面，在节点组中选择一个延迟较低的节点，或保持「自动选择」。打开浏览器访问常用网站，能正常打开就完成了。
::

::tip
旧版本 FlClash 没有启动按钮，直接打开仪表盘上的「系统代理」开关即可。

![旧版 FlClash 打开系统代理开关](/images/flclash/install5.webp)
::

## 进阶设置

### 虚拟网卡（TUN 模式）

仪表盘上的 **虚拟网卡** 开关就是 TUN 模式，可以接管不走系统代理的程序（如游戏、命令行工具）。电脑上开启时可能需要管理员权限。系统代理和虚拟网卡一般二选一即可，详见[高级设置](/zh-CN/installation-guide/advanced-settings)。

### 更新订阅

在 **配置** 页面点击右上角的刷新按钮，可以重新拉取所有订阅。

## 常见问题

::accordion
  :::accordion-item{label="提交订阅后提示导入失败？"}
  确认订阅链接复制完整、订阅没有过期，并且设备当前可以正常联网。仍然失败可以参考[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::

  :::accordion-item{label="安卓安装时提示「解析包出错」？"}
  通常是下载了不匹配的安装包，例如在手机上安装了 `x86_64` 版本。请重新下载 `android-arm64-v8a.apk`。
  :::

  :::accordion-item{label="macOS 提示「已损坏，无法打开」？"}
  打开「终端」执行下面的命令，然后重新打开 FlClash：

  ```bash
  sudo xattr -r -c /Applications/FlClash.app
  ```
  :::

  :::accordion-item{label="代理已启动，网页还是打不开？"}
  先在代理页面换一个能通过测速的节点；确认出站模式为「规则」；浏览器装了其他代理扩展时请先停用。
  :::
::
