Clash Box 是面向 **HarmonyOS NEXT（纯血鸿蒙）** 的原生 Clash 客户端，内置 Mihomo（Clash Meta）内核，支持 Shadowsocks、VMess、VLESS、Trojan、Hysteria2 等主流协议。项目大部分代码已开源。

| 支持平台 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| HarmonyOS NEXT | Mihomo | GPL-3.0（大部分代码开源） | 免费 |

![Clash Box 鸿蒙客户端](/images/clash-box/install1.webp)

::tip
**先确认系统版本**：HarmonyOS 4 及更早版本仍可安装安卓应用，直接使用 [Clash Meta for Android](/zh-CN/client-guides/clash-meta-for-android) 更简单。HarmonyOS NEXT 如果不想折腾侧载，可以通过[卓易通安装 Clash](/zh-CN/client-guides/zyt-clash)。
::

## 下载

Clash Box 在官方 GitHub 发布，安装包为未签名的 `.hap` 文件（文件名包含 `unsigned.hap`），需要自行签名后侧载安装。

::callout{icon="i-simple-icons-github" to="https://github.com/xiaobaigroup/ClashBox/releases/latest" target="_blank"}
**前往 GitHub 下载 Clash Box**：官方发布页，始终是最新版本。
::

## 侧载安装

Clash Box 目前没有在中国大陆区华为应用市场上架。如果你所在地区的应用市场能搜到，直接安装即可；搜不到时，需要用电脑把 `.hap` 签名后侧载到手机。官方推荐使用 **Auto-installer** 或 **DevEco Testing** 完成签名和安装，具体操作请按照工具自身的说明进行。

::warning
- **签名需要中国大陆 IP**：华为的签名服务器会拒绝非中国大陆 IP 的请求，在海外签名时需要先切换到中国大陆网络。
- **证书有效期**：自签名安装的应用默认只有 **14 天** 有效期，完成开发者实名认证后可延长到 **180 天**。到期后需要重新签名安装。
::

## 使用教程

::steps
### 准备订阅链接

Clash Box 只是客户端，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接。

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 添加配置

打开 Clash Box，点击底部的 **配置**，再点击右下角的 **+**，粘贴订阅链接并保存。

### 启动代理

回到 **主页**，分流模式选择 **规则**，点击右下角的按钮启动。首次启动按提示允许 VPN 权限，按钮开始计时即表示已连接。

## 常见问题

::accordion
  :::accordion-item{label="安装时提示签名失败？"}
  确认电脑当前使用中国大陆网络，并且手机已开启开发者模式和 USB 调试。仍然失败时，可以改用[卓易通](/zh-CN/client-guides/zyt-clash)安装安卓版客户端。
  :::

  :::accordion-item{label="用了两周后打不开了？"}
  这是自签名证书过期（默认 14 天）。重新签名安装即可；完成开发者实名认证后，有效期可延长到 180 天。
  :::

  :::accordion-item{label="启动后无法上网？"}
  在「代理」页面换一个节点，确认分流模式为「规则」，并检查订阅是否过期。更多排查步骤见[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::
::
