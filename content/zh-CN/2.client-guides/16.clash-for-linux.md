[clashctl](https://github.com/nelvko/clashctl){target="_blank"}（原名 clash-for-linux-install）是一套开源的 Linux 命令行管理脚本。它可以一键部署 Mihomo 内核，并提供订阅管理、终端代理开关、TUN 模式、Web 面板等功能，适合没有图形界面的服务器，也适合习惯命令行的桌面用户。

| 运行环境 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| 主流 Linux 发行版及容器环境 | Mihomo（默认）/ Clash | MIT | 免费 |

::tip
如果你使用的是带图形界面的 Linux 桌面，也可以直接安装 [Clash Verge Rev](/zh-CN/client-guides/clash-verge) 或 [FlClash](/zh-CN/client-guides/flclash)。
::

## 安装

::steps
### 检查依赖

安装脚本需要 `curl`、`tar`、`gzip`、`unzip` 和 `sha256sum`，缺少时先用包管理器安装：

:::code-group
```bash [Debian / Ubuntu]
sudo apt update && sudo apt install -y curl tar gzip unzip coreutils
```

```bash [CentOS / Rocky / Fedora]
sudo dnf install -y curl tar gzip unzip coreutils
```

```bash [Arch]
sudo pacman -S --needed curl tar gzip unzip coreutils
```
:::

### 执行安装脚本

```bash
curl -fsSL https://raw.githubusercontent.com/nelvko/clashctl/HEAD/install.sh | bash
```

脚本会自动下载项目、部署内核并注册 `clashctl` 命令。普通用户和 root 用户都可以安装，支持 systemd 和 OpenRC。安装完成后重新打开终端，让命令生效。

:::tip
安装时可以直接带上订阅：

```bash
curl -fsSL https://raw.githubusercontent.com/nelvko/clashctl/HEAD/install.sh | bash -s -- --sub "<订阅链接>"
```

服务器访问 GitHub 较慢时，可以用 `--gh-proxy <地址>` 参数指定你信任的 GitHub 加速地址。
:::
::

## 使用教程

::steps
### 准备订阅链接

clashctl 只是管理工具，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接。

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 添加订阅

```bash
clashctl sub add --use "<订阅链接>"
```

订阅链接包含 `&` 等特殊字符，务必用双引号括起来。`--use` 表示添加后立即启用。

### 开启代理

```bash
clashctl on
curl -I https://www.google.com
```

`clashctl on` 会自动启动内核，并为**当前终端**设置代理环境变量。第二条命令返回 HTTP 状态码即表示代理生效。
::

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `clashctl on` / `clashctl off` | 开启 / 关闭当前终端的代理（`off` 默认不停止内核） |
| `clashctl start` / `clashctl stop` | 仅启动 / 停止内核 |
| `clashctl status` | 查看内核状态、终端代理状态和代理地址 |
| `clashctl sub ls` | 查看订阅列表 |
| `clashctl sub use <名称>` | 切换订阅 |
| `clashctl sub update` | 更新当前订阅（`--all` 更新全部） |
| `clashctl node` | 切换节点 |
| `clashctl log` | 查看日志 |
| `clashctl upgrade` | 升级内核 |
| `clashctl update` | 更新 clashctl 脚本 |

## 进阶设置

### Web 控制面板

```bash
clashctl ui          # 输出面板访问地址
clashctl secret      # 查看访问密钥
clashctl secret "<新密钥>"   # 修改密钥
```

在浏览器中打开面板地址即可图形化切换节点、查看连接。服务器上的面板不建议直接暴露到公网，优先通过 SSH 端口转发访问。

### TUN 模式

```bash
clashctl tun on      # 开启
clashctl tun off     # 关闭
clashctl tun         # 查看状态
```

TUN 模式会接管系统全部流量（包括 Docker 容器），不再依赖终端环境变量。部分精简内核或容器环境不支持 TUN。概念说明见[高级设置](/zh-CN/installation-guide/advanced-settings)。

### Mixin 自定义配置

Mixin 会与订阅配置合并且优先级更高，适合自定义规则、DNS 和策略组：

```bash
clashctl mixin       # 查看 Mixin 配置
clashctl mixin -e    # 编辑 Mixin，保存后自动生效
clashctl mixin -c    # 查看订阅原始配置
clashctl mixin -r    # 查看内核实际运行的配置
```

### 卸载

```bash
clashctl off
bash "$CLASHCTL_HOME/uninstall.sh"
```

先执行 `clashctl off` 清理当前终端的代理变量，卸载脚本无法清理这一项。卸载会删除安装目录及其中的数据，需要保留的配置请提前备份。

## 常见问题

::accordion
  :::accordion-item{label="添加订阅失败？"}
  确认订阅链接用双引号括起来、订阅没有过期。订阅格式不兼容时，可以加上 `--convert` 参数用本地转换器重新拉取：`clashctl sub update --convert`。
  :::

  :::accordion-item{label="clashctl on 之后还是无法联网？"}
  依次检查：`clashctl status` 确认内核正在运行；`clashctl log` 查看是否有报错；`echo $http_proxy` 确认当前终端已设置代理变量；订阅中是否有可用节点。注意代理变量只对执行了 `clashctl on` 的终端生效，新开终端需要重新执行。
  :::

  :::accordion-item{label="代理端口和教程里的不一样？"}
  实际端口会因环境不同而变化（例如默认端口已被占用），请以 `clashctl status` 显示的代理地址为准。
  :::

  :::accordion-item{label="Web 面板打不开？"}
  确认内核正在运行，防火墙已放行面板端口；远程服务器请使用服务器 IP 访问，或通过 SSH 端口转发到本地。
  :::
::
