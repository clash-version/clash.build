Clash Meta for Android（简称 CMFA）由 MetaCubeX 团队维护，是已停更的 Clash for Android 的开源继任版本。它内置 Mihomo（Clash Meta）内核，支持 VLESS、Hysteria2、TUIC 等新协议，界面和老版本几乎一致，是目前安卓手机上最常用的 Clash 客户端。

| 支持平台 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| Android | Mihomo | GPL-3.0 | 免费 |

## 下载

CMFA 只在官方 GitHub 发布安装包。打开发布页后，在最新版本的 **Assets** 列表里按下表选择文件：

| 设备 | 文件名包含 | 说明 |
| --- | --- | --- |
| 绝大多数安卓手机 | `meta-arm64-v8a-release.apk` | 2017 年以后的手机基本都选这个 |
| 不确定手机架构 | `meta-universal-release.apk` | 通用版，体积更大，兼容所有设备 |
| 老旧安卓手机 | `meta-armeabi-v7a-release.apk` | 32 位老机型 |

::callout{icon="i-simple-icons-github" to="https://github.com/MetaCubeX/ClashMetaForAndroid/releases/latest" target="_blank"}
**前往 GitHub 下载 Clash Meta for Android**：官方发布页，始终是最新版本。
::

::tip
华为、荣耀手机：HarmonyOS 4 及更早版本可以直接安装 APK；HarmonyOS NEXT（纯血鸿蒙）请参考 [Clash Box](/zh-CN/client-guides/clash-box) 或[卓易通安装 Clash](/zh-CN/client-guides/zyt-clash)。
::

## 使用教程

::steps
### 安装应用

点击下载好的 `.apk` 安装。如果系统提示「禁止安装未知来源应用」，按提示允许当前浏览器或文件管理器安装。

### 准备订阅链接

CMFA 只是客户端，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接（通常在「一键订阅」或「复制订阅地址」中）。

![在服务商后台复制订阅链接](/images/copy-sub.webp)

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 从 URL 导入订阅

打开 CMFA，点击 **配置** → 右上角 **+** → **URL**。在「URL」一栏粘贴订阅链接，名称随意填写，然后点击右上角的 **保存** 图标。

保存后返回配置列表，点击刚才导入的配置，使它处于选中状态。

### 启动代理

回到首页，点击 **已停止** 按钮启动。首次启动会请求 VPN 权限，点击 **确定**。按钮变为 **运行中** 即表示成功。

:::

### 选择节点

点击首页的 **代理**，在节点组中选择 **自动选择** 或延迟较低的节点。点击右上角的闪电图标可以一键测速。
::

## 进阶设置

### 分应用代理

只想让部分 App 走代理，或者想排除某些 App（例如银行类应用）：

1. 进入 **设置 → 网络**。
2. 在 **访问控制模式** 中选择「仅允许已选择的应用」或「不允许已选择的应用」。
3. 在 **访问控制应用包列表** 中勾选对应的 App，然后重启代理生效。

### 更新订阅

进入 **配置** 页面，点击订阅右侧的菜单选择更新。编辑配置时也可以设置 **自动更新** 间隔。

## 常见问题

::accordion
  :::accordion-item{label="安装时提示「解析包出错」？"}
  一般是安装包与手机架构不匹配，或者下载不完整。请重新下载 `meta-universal-release.apk` 通用版再试。
  :::

  :::accordion-item{label="导入订阅时提示失败？"}
  确认订阅链接复制完整、订阅没有过期，并且手机当前可以正常联网。仍然失败可以参考[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::

  :::accordion-item{label="显示运行中，但还是打不开网站？"}
  在「代理」页面换一个能通过测速的节点；确认没有同时开启其他 VPN 应用；检查是否在分应用代理中排除了当前使用的 App。
  :::

  :::accordion-item{label="和 Clash for Android 有什么区别？"}
  CMFA 是 Clash for Android 停更后的继任版本，界面和用法基本相同，但内核换成了持续更新的 Mihomo，支持更多新协议。原来的订阅链接可以直接导入使用。
  :::
::
