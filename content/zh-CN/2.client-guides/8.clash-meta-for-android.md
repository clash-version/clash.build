## 🛠️ 安装步骤详解

### 步骤 1：安装应用 APK

- 下载 `.apk` 文件后点击安装。
- 如遇系统提示“安装来自未知来源的应用”，请点击“允许”或在设置中放行。
- 鸿蒙系统用户：如果你的系统是 HarmonyOS 4.0 及以下（兼容安卓），可直接安装此版本。如果是 **HarmonyOS NEXT**，请移步 [Clash Box](/zh-CN/client-guides/clash-box)。

### 步骤 2：获取 Clash 订阅

::note
Clash Meta for Android 本身不提供代理服务。继续操作前，请准备由可信服务提供方提供的订阅地址或配置文件。👉[戳我看看](https://iv.coolgo.me/aff.php?aff=35)
::

### 步骤 3：导入订阅 (关键步骤)

1. 登录你的服务提供方后台。
2.  找到 **“一键订阅”** -> **“复制订阅地址”**。
3.  打开 Clash Meta for Android App。
4.  点击主界面的 **“订阅”** (Profile)。
5.  点击右上角的 ** `+` 号** -> **“从 URL 导入”**。
6.  粘贴订阅链接，**名称**随便填（例如：我的订阅），点击右上角保存图标。
7.  选中刚刚导入的订阅（选中后圆圈会变色）。
8.  返回主界面。

### 步骤 4：开启代理与节点选择

1.  或者点击底部的 **“代理”** (Proxy)，在这里你可以看到所有的节点列表。
2.  点击右上角的 **⚡图标** 可以测试所有节点的延迟。
3.  点击一个绿色的节点（或者是“自动选择”）。
4.   **已停止** 按钮（变成 **运行中**）。首次启动会弹出 VPN 授权申请，点击 **“确定/允许”**。

## ⚙️ 进阶订阅与常见问题

### 只想让特定 App 走代理 (分应用代理)
1. 进入 **设置** -> **网络**。
2. 找到 **分应用代理** (Access Control)。
3. 开启开关，模式选择 **“仅允许已选应用”** (Allow selected) 或 **“仅拒绝已选应用”**。
4. 勾选你想让其走代理的 App（如 Google Play, YouTube, Chrome 等）。
