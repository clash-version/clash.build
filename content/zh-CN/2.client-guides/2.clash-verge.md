Clash Verge Rev 是基于 Tauri 开发的开源桌面客户端，内置 Mihomo（Clash Meta）内核。原版 Clash Verge 停更后，它由社区接手持续维护，界面清晰、更新活跃，是目前电脑端最推荐的 Clash 客户端。

| 支持平台 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| Windows · macOS · Linux | Mihomo | GPL-3.0 | 免费 |

![Clash Verge Rev 主界面](/images/clash-verge-rev/preview-1.webp)

## 下载

Clash Verge Rev 只在官方 GitHub 发布安装包。打开发布页后，在最新版本的 **Assets** 列表里按下表选择文件：

| 设备 | 文件名包含 | 说明 |
| --- | --- | --- |
| Windows 电脑 | `x64-setup.exe` | 绝大多数 Intel / AMD 电脑选这个 |
| Windows ARM 设备 | `arm64-setup.exe` | 骁龙等 ARM 处理器的 Windows 设备 |
| Mac（Apple 芯片） | `aarch64.dmg` | M1、M2、M3、M4 等 Apple 芯片 |
| Mac（Intel 芯片） | `x64.dmg` | Intel 处理器的 Mac |
| Linux | `amd64.deb` / `x86_64.rpm` | Debian、Ubuntu 选 deb；Fedora、openSUSE 选 rpm |

::callout{icon="i-simple-icons-github" to="https://github.com/clash-verge-rev/clash-verge-rev/releases/latest" target="_blank"}
**前往 GitHub 下载 Clash Verge Rev**：官方发布页，始终是最新版本。
::

::tip
不确定电脑是什么芯片？Windows 在「设置 → 系统 → 系统信息」查看「系统类型」；Mac 点左上角苹果菜单 →「关于本机」查看「芯片」。请只从官方发布页下载，不要使用来路不明的网盘或群文件。
::

## 安装

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  双击下载好的 `setup.exe`，按提示完成安装。如果出现「Windows 已保护你的电脑」，点击 **更多信息 → 仍要运行**。
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  打开 `.dmg`，把 Clash Verge 拖进「应用程序」文件夹。首次打开如果提示无法验证开发者，到 **系统设置 → 隐私与安全性**，点击 **仍要打开**。
  :::

  :::tabs-item{label="Linux" icon="i-simple-icons-linux"}
  在下载目录执行对应的安装命令：

  ```bash
  # Debian / Ubuntu
  sudo apt install ./Clash.Verge_*_amd64.deb

  # Fedora / openSUSE
  sudo dnf install ./Clash.Verge-*.x86_64.rpm
  ```
  :::
::

## 使用教程

::steps
### 准备订阅链接

Clash Verge Rev 只是客户端，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接（通常在「一键订阅」或「复制订阅地址」中）。

![在服务商后台复制订阅链接](/images/copy-sub.webp)

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 导入订阅

点击左侧 **订阅**，把订阅链接粘贴到顶部输入框，然后点击 **导入**。

![Clash Verge Rev 粘贴订阅链接并导入](/images/clash-verge-rev/add-config-1.webp)

列表中出现订阅卡片，并显示已用流量和更新时间，就说明导入成功。

![Clash Verge Rev 订阅导入成功](/images/clash-verge-rev/add-config-2.webp)

### 开启系统代理

回到 **首页**，在「网络设置」中选择 **系统代理**，再打开下方的 **系统代理** 开关。代理模式保持 **规则** 即可。

![Clash Verge Rev 开启系统代理](/images/clash-verge-rev/app-start.webp)

### 选择节点

进入 **代理** 页面，点击 **连通性测试** 图标测速，然后选择 **自动选择**，或手动选一个延迟较低的节点。打开浏览器访问常用网站，能正常打开就完成了。

![Clash Verge Rev 节点测速与选择](/images/clash-verge-rev/node-test.webp)
::

## 进阶设置

### TUN 模式（虚拟网卡）

系统代理只对遵循系统代理设置的程序生效。游戏、终端命令行等不走系统代理的程序，需要开启 TUN 模式来接管全部流量。

在首页「网络设置」中切换到 **虚拟网卡模式**，再打开开关。Windows 首次开启时，请按提示安装服务模式或以管理员身份运行。

![Clash Verge Rev 开启虚拟网卡模式](/images/clash-verge-rev/open-tun.webp)

::warning
系统代理和 TUN 模式一般二选一即可。开启 TUN 后如果无法上网，先关闭它再排查。更多说明见[高级设置](/zh-CN/installation-guide/advanced-settings)。
::

### 开启 IPv6

进入 **设置 → Clash 设置**，打开 **IPv6** 开关。

![Clash Verge Rev 开启 IPv6](/images/clash-verge-rev/open-ipv6.webp)

IPv6 需要本地网络支持。可以先访问 [test-ipv6.com](https://test-ipv6.com/){target="_blank"} 检测：页面能显示 IPv6 地址才说明可用。如果检测不通过，通常是运营商或路由器没有开启 IPv6，此时保持关闭即可。

### 更新订阅

服务商调整节点后，进入 **订阅** 页面，点击订阅卡片上的刷新按钮重新拉取配置。

![Clash Verge Rev 更新订阅](/images/clash-verge-rev/update-config-1.webp)

### 检测 AI 与流媒体解锁

左侧 **测试** 页面可以一键检测 ChatGPT、Claude、Netflix 等服务在当前节点是否可用，换节点后可以重新测一次。

![Clash Verge Rev 流媒体与 AI 解锁检测](/images/clash-verge-rev/media_test.webp)

## 常见问题

::accordion
  :::accordion-item{label="导入订阅时提示失败怎么办？"}
  先确认订阅链接复制完整、没有多余空格，并且订阅没有过期。然后检查电脑能否正常联网，再重新导入。仍然失败可以参考[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::

  :::accordion-item{label="已经开启代理，网页还是打不开？"}
  依次检查：系统代理开关是否打开、当前节点能否通过测速、代理模式是否为「规则」。浏览器装了其他代理扩展时，请先停用再试。
  :::

  :::accordion-item{label="macOS 提示「已损坏，无法打开」？"}
  这是 macOS 对未公证应用的拦截，并不是文件真的损坏。打开「终端」执行下面的命令后重新打开即可：

  ```bash
  sudo xattr -r -c "/Applications/Clash Verge.app"
  ```
  :::

  :::accordion-item{label="怎么升级到新版本？"}
  客户端会在有新版本时提示更新；也可以到官方发布页下载最新安装包，直接覆盖安装，订阅和设置会保留。
  :::
::
