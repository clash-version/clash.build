Clash for Android（简称 CFA）是由开发者 Kr328 创建的经典安卓 Clash 客户端。2023 年 11 月，项目停止维护，官方仓库也已删除。

::warning
**Clash for Android 已停止维护，本站不再提供下载。** 官方渠道已经关闭，网上流传的安装包都来自第三方转存，无法确认是否被篡改。请改用开源继任版本 [Clash Meta for Android](/zh-CN/client-guides/clash-meta-for-android)，界面和用法几乎完全一样。
::

| 项目 | 现状 |
| --- | --- |
| 最后版本 | 2.5.12 |
| 开源情况 | 曾开源，官方仓库已删除 |
| 新协议支持 | 不支持 VLESS、Hysteria2、TUIC 等 |
| 推荐替代 | [Clash Meta for Android](/zh-CN/client-guides/clash-meta-for-android) |

## 迁移到 Clash Meta for Android

::steps
### 安装 Clash Meta for Android

按照 [Clash Meta for Android 教程](/zh-CN/client-guides/clash-meta-for-android) 从官方 GitHub 下载并安装。两个应用可以同时安装，互不影响。

### 停止 Clash for Android

在 CFA 首页点击 **运行中** 停止代理，避免两个 VPN 同时运行。

### 导入同一个订阅

把原来的订阅链接在 CMFA 中通过 **配置 → + → URL** 导入，选中后启动即可。确认能正常上网后，可以卸载 CFA。
::

## 老用户使用说明

如果你暂时还在使用已安装的 CFA，可以参考下面的基本操作，界面与 CMFA 相同。

::steps
### 导入订阅

打开 CFA，点击 **配置** → 右上角 **+** → **URL**，粘贴订阅链接并保存，然后选中这个配置。

:::div{.grid.gap-4.grid-cols-2}

![Clash for Android 点击加号添加配置](/images/clash-meta-for-android/copy-install2.png)
:::

### 启动代理

回到首页，点击 **已停止** 按钮启动，首次启动按提示允许 VPN 权限。

:::

## 常见问题

::accordion
  :::accordion-item{label="订阅能导入，但所有节点都连不上？"}
  如果服务商使用的是 VLESS、Hysteria2 等新协议，CFA 无法识别这些节点。CFA 已无法升级，请换用 [Clash Meta for Android](/zh-CN/client-guides/clash-meta-for-android)。
  :::

  :::accordion-item{label="新手机安装时提示「解析包出错」？"}
  CFA 已经长期没有适配新版安卓系统，部分新机型无法安装。请直接使用 Clash Meta for Android。
  :::

  :::accordion-item{label="鸿蒙手机能用吗？"}
  HarmonyOS 4 及更早版本可以安装安卓应用，但同样建议使用 Clash Meta for Android；HarmonyOS NEXT 请参考 [Clash Box](/zh-CN/client-guides/clash-box)。
  :::
::
