ClashX 是一款常驻 macOS 菜单栏的 Clash 客户端，以轻巧、原生著称。2023 年 11 月，作者删除了官方仓库，ClashX 和收费的 ClashX Pro 都已停止更新。

::warning
**ClashX 已停止维护，本站不再提供下载。** 官方渠道已经关闭，网上流传的安装包都来自第三方转存，其中 ClashX Pro 还是闭源版本，无法确认是否被篡改。Mac 用户建议改用开源且持续更新的 [Clash Verge Rev](/zh-CN/client-guides/clash-verge)。
::

| 项目 | 现状 |
| --- | --- |
| 支持平台 | macOS |
| 开源情况 | ClashX 曾开源，ClashX Pro 闭源，官方仓库均已删除 |
| 新协议支持 | 不支持 VLESS、Hysteria2 等新协议 |
| 推荐替代 | [Clash Verge Rev](/zh-CN/client-guides/clash-verge)（支持 Apple 芯片和 Intel 芯片） |

## 迁移到 Clash Verge Rev

::steps
### 安装 Clash Verge Rev

按照 [Clash Verge Rev 教程](/zh-CN/client-guides/clash-verge) 下载 Mac 版：Apple 芯片选 `aarch64.dmg`，Intel 芯片选 `x64.dmg`。

### 退出 ClashX

点击菜单栏的 ClashX 图标，取消勾选 **设置为系统代理**，然后选择 **退出**。

### 导入同一个订阅

订阅链接在任何 Clash 客户端中都通用。把原来的订阅链接粘贴到 Clash Verge Rev 的 **订阅** 页面导入，再开启系统代理即可。
::

## 老用户使用说明

如果你暂时还在使用已安装的 ClashX，可以参考下面的基本操作。

::steps
### 添加托管配置

点击菜单栏的 ClashX 图标，依次选择 **配置 → 托管配置 → 管理**。

![ClashX 菜单栏打开托管配置管理](/images/clashx/install2.webp)

在弹出的窗口中点击 **添加**，填写订阅链接（Url）和配置名称（Config Name），点击 **确定**。

![ClashX 添加托管配置文件](/images/clashx/install3.webp)

### 设置为系统代理

再次点击菜单栏图标，确认已选中刚才添加的配置，然后勾选 **设置为系统代理**。

![ClashX 设置为系统代理](/images/clashx/install4.webp)
::

## 常见问题

::accordion
  :::accordion-item{label="更新托管配置时失败？"}
  如果订阅中包含 VLESS、Hysteria2 等新协议节点，ClashX 的旧内核无法解析，会导致配置更新失败。这种情况只能换用 [Clash Verge Rev](/zh-CN/client-guides/clash-verge) 等新客户端。
  :::

  :::accordion-item{label="新版 macOS 打不开 ClashX？"}
  ClashX 已经长期没有适配新系统，遇到兼容问题时也不会再有修复。建议直接迁移到 Clash Verge Rev。
  :::

  :::accordion-item{label="勾选了系统代理还是无法上网？"}
  先在菜单栏的代理列表中换一个节点，并确认出站模式为「规则」。仍然不行可以参考[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::
::
