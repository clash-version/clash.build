## Clash Mi 程序配置

### 1. 程序安装

- **Windows**: 下载 `.exe` 安装包并运行。如果遇到 SmartScreen 提示，点击“更多信息”并选择“仍要运行”。
- **macOS**: 下载 `.dmg` 文件，将 Clash Mi 拖入应用程序文件夹。如果无法打开，请在“系统设置 > 隐私与安全性”中允许运行。
- **Android**: 下载 `.apk` 文件并安装，需允许从未知来源安装应用。
- **iOS**: 直接从 App Store 下载，或通过 TestFlight 加入测试版。
- **Linux**: 支持 Debian/Ubuntu (`.deb`) 安装。

### 2. 获取订阅

::note
Clash Mi 本身不提供代理服务。继续操作前，请准备由可信服务提供方提供的订阅地址或配置文件。👉[戳我看看](https://iv.coolgo.me/aff.php?aff=35)
::

### 3. 导入配置

打开 Clash Mi，进入配置管理界面。

1.  在主界面**我的配置** 管理。
2.  点击按钮➕号。
3.  选择 *添加配置链接**。
4.  粘贴准备的订阅配置。
5.  点击确认

::div{.grid.gap-4.sm:grid-cols-2}
![ClashMi 订阅导入流程 1](/images/clashmi/add-config-1.webp)

![ClashMi 订阅导入流程 2](/images/clashmi/add-config-2.webp)

![ClashMi 订阅导入流程 3](/images/clashmi/add-config-3.webp)
::

### 4. 启动程序

启动程序以连接网络。

1.  如果是首次运行，系统会询问权限（Android/iOS）或系统代理权限（Windows/macOS），点击 **允许 (Allow)**。
2.  按钮变色且显示已连接状态，即表示代理开启成功。

::div{.grid.gap-4.sm:grid-cols-2}
![ClashMi 启动程序 1](/images/clashmi/app-start.webp)
::

### 5. 选择节点

配置选中后，返回主界面或代理界面。

1.  点击 **Proxy (代理)** 选项卡，选择出口
2.  建议使用 **Rule (规则)** 模式，实现自动分流。

::div{.grid.gap-4.sm:grid-cols-2}

::

## 常见问题

::info
**无法连接？**
1.  检查订阅是否过期。
2.  尝试更新订阅（Update Subscription）。
3.  检查系统时间是否同步。
4.  Windows 用户如果开启了 TUN 模式，请确保以管理员身份运行。
::

## 应用特性

- **跨平台统一**：基于 Flutter 开发，确保 Windows、macOS、Android、iOS 端拥有一致的体验。
- **轻量极速**：应用体积小巧，启动速度快，资源占用极低。
- **内核强劲**：内置 Mihomo 核心，即使在轻量级界面下也能提供强大的网络性能。
- **极简设计**：去繁就简，专注于核心的代理与分流功能。
