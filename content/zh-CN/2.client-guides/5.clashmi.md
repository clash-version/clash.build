Clash Mi 是基于 Flutter 开发的开源客户端，内置 Mihomo（Clash Meta）内核。它体积小、启动快，手机和电脑使用同一套界面，iPhone 用户也可以在 App Store 免费下载。

| 支持平台 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| Windows · macOS · Linux · Android · iOS | Mihomo | GPL-3.0 | 免费 |

## 下载

电脑和安卓版在官方 GitHub 发布，iOS 版在 App Store 上架。打开 GitHub 发布页后，在最新版本的 **Assets** 列表里按下表选择文件：

| 设备 | 文件名包含 | 说明 |
| --- | --- | --- |
| Windows 电脑 | `windows_x64.exe` | 安装版；`windows_x64.zip` 为免安装版 |
| Mac | `macos_universal.dmg` | Apple 芯片和 Intel 芯片通用 |
| Linux | `linux_amd64.AppImage` / `.deb` / `.rpm` | 按发行版选择 |
| 安卓手机 | `android_arm64-v8a.apk` | 绝大多数安卓手机选这个 |
| 老旧安卓手机 | `android_armeabi-v7a.apk` | 32 位老机型 |

::callout{icon="i-simple-icons-github" to="https://github.com/KaringX/clashmi/releases/latest" target="_blank"}
**前往 GitHub 下载 Clash Mi**：电脑版和安卓版的官方发布页。
::

::callout{icon="i-simple-icons-apple" to="https://apps.apple.com/app/clash-mi/id6744321968" target="_blank"}
**在 App Store 获取 Clash Mi**：iPhone / iPad 版，免费。中国大陆区商店无法搜索，需要使用其他地区的 Apple ID。想提前体验新版本可以加入官方 [TestFlight 测试](https://testflight.apple.com/join/bjHXktB3){target="_blank"}。
::

::tip
系统要求：iOS 15、macOS 12、Android 8、Windows 10 及以上版本。
::

## 安装

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  双击 `.exe` 按提示安装。如果出现「Windows 已保护你的电脑」，点击 **更多信息 → 仍要运行**。
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  打开 `.dmg`，把 Clash Mi 拖进「应用程序」文件夹。首次打开如果被拦截，到 **系统设置 → 隐私与安全性** 点击 **仍要打开**。
  :::

  :::tabs-item{label="Android" icon="i-simple-icons-android"}
  点击下载好的 `.apk` 安装，按提示允许安装未知来源应用。
  :::

  :::tabs-item{label="iOS" icon="i-lucide-smartphone"}
  在 App Store 登录非中国大陆区的 Apple ID，打开上方链接安装即可。
  :::
::

## 使用教程

::steps
### 复制订阅链接

Clash Mi 只是客户端，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接。

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 添加配置链接

在首页点击 **我的配置** 右侧的 **+**，选择 **添加配置链接**。把订阅链接粘贴到「配置链接」，备注随意填写（例如「我的订阅」），然后点击右上角的 **✓** 保存。

:::div{.grid.gap-4.sm:grid-cols-3}
![Clash Mi 点击我的配置旁的加号](/images/clashmi/add-config-1.webp)

![Clash Mi 选择添加配置链接](/images/clashmi/add-config-2.webp)

![Clash Mi 粘贴订阅链接并保存](/images/clashmi/add-config-3.webp)
:::

### 连接

回到首页，打开顶部的开关，状态变为「已连接」即表示成功。首次连接时，手机会请求添加 VPN 配置，电脑会请求系统代理权限，点击 **允许** 即可。代理模式保持 **规则**。

![Clash Mi 连接成功](/images/clashmi/app-start.webp)

### 选择节点

点击首页的 **代理**，选择 **自动选择**，或在「节点选择」中手动选一个延迟较低的节点。

:::div{.grid.gap-4.sm:grid-cols-2}
![Clash Mi 选择自动选择](/images/clashmi/node-select-1.webp)

![Clash Mi 节点选择分组](/images/clashmi/node-select-2.webp)
:::
::

## 常见问题

::accordion
  :::accordion-item{label="连接不上或所有节点都超时？"}
  依次检查：订阅是否过期、是否已在「我的配置」中更新订阅、设备时间是否准确。Windows 使用 TUN 模式时，请以管理员身份运行 Clash Mi。更多排查步骤见[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::

  :::accordion-item{label="App Store 搜不到 Clash Mi？"}
  中国大陆区的 App Store 没有上架，需要切换到其他地区的 Apple ID。也可以直接打开本页的 App Store 链接。
  :::

  :::accordion-item{label="怎么更新订阅？"}
  在首页点击 **我的配置** 进入配置列表，对订阅执行更新即可。添加配置时也可以设置自动更新间隔。
  :::
::
