HarmonyOS NEXT（纯血鸿蒙）不能直接安装安卓 APK。除了侧载原生客户端 [Clash Box](/zh-CN/client-guides/clash-box)，还可以通过 **卓易通** 运行安卓版 Clash 客户端。这种方式不需要电脑和签名证书，操作和在安卓手机上基本一样。

::note
卓易通是华为应用市场上架的安卓应用兼容工具，可以在 HarmonyOS NEXT 上安装和运行安卓应用。HarmonyOS 4 及更早版本仍可直接安装 APK，不需要卓易通，直接参考 [Clash Meta for Android 教程](/zh-CN/client-guides/clash-meta-for-android) 即可。
::

## 两种方式对比

| 对比项 | 卓易通 + 安卓客户端 | Clash Box 侧载 |
| --- | --- | --- |
| 安装难度 | 简单，手机上即可完成 | 需要电脑签名后侧载 |
| 有效期 | 长期可用 | 自签名默认 14 天，需定期重签 |
| 可选客户端 | Clash Meta for Android、FlClash 等 | 仅 Clash Box |
| 运行方式 | 在兼容环境中运行 | 鸿蒙原生运行 |

## 下载

在卓易通中推荐安装以下开源客户端，均从官方 GitHub 下载：

| 客户端 | 推荐文件 | 说明 |
| --- | --- | --- |
| [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid/releases/latest){target="_blank"} | `meta-arm64-v8a-release.apk` | 推荐，社区活跃，兼容性好 |
| [FlClash](https://github.com/chen08209/FlClash/releases/latest){target="_blank"} | `android-arm64-v8a.apk` | 界面美观，和电脑版一致 |

## 安装

::steps
### 安装卓易通

打开华为应用市场，搜索 **卓易通** 并安装。首次打开时按提示完成初始化，并授予需要的权限。

### 下载客户端安装包

用手机浏览器打开上方的 GitHub 链接，下载对应的 `.apk` 文件，保存到手机本地存储。

### 在卓易通中安装

打开卓易通，选择安装本地应用，找到刚才下载的 `.apk` 文件并安装。安装完成后，在卓易通中即可打开 Clash 客户端。
::

## 使用教程

以下以 Clash Meta for Android 为例，界面与在安卓手机上完全一致。

::steps
### 准备订阅链接

Clash 客户端本身不提供节点。请先登录你使用的服务商后台，复制订阅链接。

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 从 URL 导入订阅

点击 **配置** → 右上角 **+** → **URL**，粘贴订阅链接，点击右上角的保存图标，然后选中这个配置。

:::div{.grid.gap-4.grid-cols-2.sm:grid-cols-3}

![CMFA 粘贴订阅链接](/images/clash-meta-for-android/copy-install4.png)
:::

### 启动代理

回到首页，点击 **已停止** 按钮启动，按提示允许 VPN 权限。按钮变为 **运行中** 即表示成功。

## 常见问题

::accordion
  :::accordion-item{label="在卓易通中安装 APK 失败？"}
  重新下载安装包，确认文件完整；检查手机存储空间是否充足；把卓易通更新到最新版本后再试。如果某个客户端始终装不上，可以换另一个客户端。
  :::

  :::accordion-item{label="客户端显示运行中，但无法上网？"}
  确认卓易通拥有网络权限，在「代理」页面换一个能通过测速的节点，并检查订阅是否过期。仍然不行可以重启卓易通和客户端，或参考[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::

  :::accordion-item{label="卓易通和 Clash Box 应该选哪个？"}
  想省事选卓易通，几分钟就能装好；想要原生体验、不介意定期重签，可以选 [Clash Box](/zh-CN/client-guides/clash-box)。
  :::
::
