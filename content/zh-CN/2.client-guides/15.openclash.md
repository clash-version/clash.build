OpenClash 是运行在 OpenWrt 路由器上的开源 Clash 插件，提供 LuCI 网页管理界面。装在路由器上后，连接这台路由器的手机、电脑、电视等设备都能自动使用代理，不需要在每台设备上单独安装客户端。

| 运行环境 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| OpenWrt（LuCI 19.07 及以上） | Mihomo | MIT | 免费 |

::note
OpenClash 适合已经刷好 OpenWrt、熟悉路由器后台的用户。如果只是在一两台设备上使用，直接安装 [Clash Verge Rev](/zh-CN/client-guides/clash-verge) 等客户端会更简单。
::

## 下载

OpenClash 在官方 GitHub 发布，按路由器使用的包管理器选择安装包：

| 包管理器 | 文件名 | 适用系统 |
| --- | --- | --- |
| opkg | `luci-app-openclash_*_all.ipk` | 大多数现有 OpenWrt 版本 |
| apk | `luci-app-openclash-*.apk` | 已改用 apk 包管理器的新版 OpenWrt |

::callout{icon="i-simple-icons-github" to="https://github.com/vernesong/OpenClash/releases/latest" target="_blank"}
**前往 GitHub 下载 OpenClash**：官方发布页，始终是最新版本。
::

::tip
不确定用哪种包管理器？SSH 登录路由器后执行 `which opkg apk`，有输出的就是当前系统使用的那个。
::

## 安装

::steps
### 安装依赖

SSH 登录路由器，根据防火墙类型安装依赖。OpenWrt 22.03 及之后的版本默认使用 nftables（Firewall4），更早的版本使用 iptables。

:::code-group
```bash [opkg · nftables]
opkg update
opkg install bash dnsmasq-full curl ca-bundle ip-full ruby ruby-yaml kmod-tun kmod-inet-diag unzip kmod-nft-tproxy luci-compat luci luci-base
```

```bash [opkg · iptables]
opkg update
opkg install bash iptables dnsmasq-full curl ca-bundle ipset ip-full iptables-mod-tproxy iptables-mod-extra ruby ruby-yaml kmod-tun kmod-inet-diag unzip luci-compat luci luci-base
```

```bash [apk · nftables]
apk update
apk add bash dnsmasq-full curl ca-bundle ip-full ruby ruby-yaml kmod-tun kmod-inet-diag unzip kmod-nft-tproxy luci-compat luci luci-base
```
:::

如果提示 `dnsmasq` 与 `dnsmasq-full` 冲突，先执行 `opkg remove dnsmasq`（apk 系统为 `apk del dnsmasq`），再重新安装依赖。

### 安装 OpenClash

**网页安装**：在 LuCI 后台打开 **系统 → 软件包**，点击 **上传软件包**，选择下载好的安装包并安装。安装完成后刷新页面，在 **服务** 菜单中会出现 **OpenClash**。

![在 OpenWrt 软件包页面安装 OpenClash](/images/openclash/install1.webp)

**命令行安装**：把安装包上传到路由器的 `/tmp` 目录后执行：

:::code-group
```bash [opkg]
opkg install /tmp/luci-app-openclash_*_all.ipk
```

```bash [apk]
apk add -q --force-overwrite --clean-protected --allow-untrusted /tmp/luci-app-openclash-*.apk
```
:::
::

## 使用教程

::steps
### 准备订阅链接

OpenClash 只是代理工具，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接。

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 添加订阅

打开 **服务 → OpenClash**，进入 **配置订阅**，点击 **添加**，填写配置名称和订阅地址后保存，再点击 **更新配置** 下载订阅。

### 启动 OpenClash

回到 **运行状态** 页面，确认配置文件已启用，点击底部的 **启动 OpenClash**。首次启动会自动下载内核，需要路由器能正常访问 GitHub，请耐心等待。

![OpenClash 运行状态页面：粘贴订阅并启动](/images/openclash/install2.webp)

### 验证

启动成功后，运行状态页会显示各项服务为运行中。用连接到这台路由器的手机或电脑访问常用网站，能正常打开就完成了。
::

## 常见问题

::accordion
  :::accordion-item{label="启动时卡在下载内核？"}
  首次启动需要从 GitHub 下载内核。如果路由器访问 GitHub 很慢，可以在电脑上从 Mihomo 官方 GitHub 下载对应路由器架构的内核，再通过 OpenClash 的文件上传功能手动上传。
  :::

  :::accordion-item{label="启动后整个网络都断了？"}
  先在运行状态页点击 **停止 OpenClash** 恢复网络，然后检查订阅是否正常、依赖是否完整安装，尤其是 `dnsmasq-full` 和防火墙相关的依赖。更多排查步骤见[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::

  :::accordion-item{label="只想让部分设备走代理？"}
  在 OpenClash 的 **插件设置** 中可以配置局域网访问控制，按 IP 或 MAC 地址指定需要代理或绕过代理的设备。
  :::
::
