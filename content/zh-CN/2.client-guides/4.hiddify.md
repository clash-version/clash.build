Hiddify 是一款开源的全平台代理客户端，基于 sing-box 内核开发。它能直接识别 Clash / Mihomo、sing-box、V2Ray 等多种订阅格式，界面简洁，导入订阅后一键即可连接，适合不想研究太多设置的用户。

| 支持平台 | 内核 | 开源协议 | 费用 |
| --- | --- | --- | --- |
| Windows · macOS · Linux · Android · iOS | sing-box | GPL-3.0 | 免费 |

## 下载

电脑和安卓版在官方 GitHub 发布，iOS 版在 App Store 上架。打开 GitHub 发布页后，在最新版本的 **Assets** 列表里按下表选择文件：

| 设备 | 文件名 | 说明 |
| --- | --- | --- |
| Windows 电脑 | `Hiddify-Windows-Setup-x64.exe` | 安装版；`Portable-x64.zip` 为免安装版 |
| Mac | `Hiddify-MacOS.dmg` | Apple 芯片和 Intel 芯片通用 |
| Linux | `Hiddify-Linux-x64.AppImage` | 也提供 `Debian-x64.deb` 和 `rpm-x64.rpm` |
| 安卓手机 | `Hiddify-Android-universal.apk` | 通用版，不确定时选这个 |

::callout{icon="i-simple-icons-github" to="https://github.com/hiddify/hiddify-app/releases/latest" target="_blank"}
**前往 GitHub 下载 Hiddify**：电脑版和安卓版的官方发布页。
::

::callout{icon="i-simple-icons-apple" to="https://apps.apple.com/app/hiddify-proxy-vpn/id6596777532" target="_blank"}
**在 App Store 获取 Hiddify**：iPhone / iPad 版，名称为「Hiddify Proxy & VPN」，免费。中国大陆区商店无法搜索，需要使用其他地区的 Apple ID。
::

## 安装

::tabs
  :::tabs-item{label="Windows" icon="i-simple-icons-windows11"}
  双击 `Setup-x64.exe`，按提示完成安装。如果出现「Windows 已保护你的电脑」，点击 **更多信息 → 仍要运行**。
  :::

  :::tabs-item{label="macOS" icon="i-simple-icons-apple"}
  打开 `.dmg`，把 Hiddify 拖进「应用程序」文件夹。首次打开如果被拦截，到 **系统设置 → 隐私与安全性** 点击 **仍要打开**。
  :::

  :::tabs-item{label="Linux" icon="i-simple-icons-linux"}
  ```bash
  chmod +x Hiddify-Linux-x64.AppImage
  ./Hiddify-Linux-x64.AppImage
  ```
  :::

  :::tabs-item{label="Android" icon="i-simple-icons-android"}
  点击下载好的 `.apk` 安装，按提示允许安装未知来源应用。安卓版的详细教程见 [Hiddify Android](/zh-CN/client-guides/hiddify-android)。
  :::
::

## 使用教程

::steps
### 复制订阅链接

Hiddify 只是客户端，本身不提供节点。请先登录你使用的服务商后台，复制订阅链接。

:::note
还没有订阅？可以参考[这里的订阅方案](https://iv.coolgo.me/aff.php?aff=35){target="_blank"}（第三方推广链接，购买前请自行核实）。订阅链接相当于账号凭证，不要分享给他人。
:::

### 从剪贴板添加

打开 Hiddify，点击主页的 **新的配置文件**，选择 **从剪贴板添加**，Hiddify 会自动读取刚才复制的链接。

![Hiddify 从剪贴板添加订阅](/images/hiddify/install2.webp)

### 设置自动更新

进入配置文件详情，点击 **自动更新**，填写更新间隔（例如 12 小时）后确认，再点右上角 **保存**。这样节点变动时会自动同步。

![Hiddify 打开自动更新设置](/images/hiddify/install3.webp)

![Hiddify 填写自动更新间隔](/images/hiddify/install4.webp)

### 一键连接

回到主页，点击中间的大按钮，下方显示「已连接」和延迟即表示成功。需要切换节点时，进入左侧 **代理** 页面选择。

![Hiddify 点击按钮连接](/images/hiddify/install5.webp)
::

## 进阶设置

### 服务模式与 TUN

Hiddify 默认以系统代理方式工作。如果游戏、命令行等程序不走代理，可以在 **配置选项** 中把 **服务模式** 改为 **VPN**，效果相当于 TUN 模式，会接管全部流量。电脑上使用 VPN 模式可能需要管理员权限。

配置选项中还有 IPv6、DNS 等设置，不了解时保持默认即可。相关概念见[高级设置](/zh-CN/installation-guide/advanced-settings)。

## 常见问题

::accordion
  :::accordion-item{label="点击「从剪贴板添加」没有反应？"}
  确认剪贴板里是完整的订阅链接（以 `https://` 开头）。也可以选择「手动输入」，把链接粘贴进去。
  :::

  :::accordion-item{label="连接成功但网页打不开？"}
  进入「代理」页面换一个延迟较低的节点；如果所有节点都超时，先在服务商后台确认订阅是否到期，再更新订阅。更多排查步骤见[故障排查](/zh-CN/installation-guide/troubleshooting)。
  :::

  :::accordion-item{label="App Store 搜索到多个 Hiddify？"}
  请认准名称为「Hiddify Proxy & VPN」的应用，或直接使用本页的 App Store 链接，避免下载名称相似的其他应用。
  :::
::
