## Windows 安装包怎么选

| 标识 | 适用设备 | 建议 |
| --- | --- | --- |
| `x64`、`x86_64`、`amd64` | 绝大多数 Intel 或 AMD 处理器电脑 | 不确定时通常选择这个版本 |
| `arm64`、`aarch64` | 骁龙处理器等 Windows ARM 设备 | 只适用于 ARM 架构设备 |
| `setup.exe`、`msi` | 希望正常安装到系统的用户 | 适合大多数用户 |
| `portable`、`zip` | 不希望安装或需要放入移动存储的用户 | 解压后运行，部分系统集成功能可能不同 |

::tip
可以打开“设置 → 系统 → 系统信息”，在“系统类型”中查看当前设备是 x64 还是 ARM64。
::

## 下载与安装提示

1. 优先下载最新的稳定版本，不熟悉测试版本时不要选择带有 `alpha`、`beta` 或 `nightly` 的文件。
2. Windows 首次运行时可能出现安全提示，请先核对发布来源和文件名称。
3. 如果旧版本正在运行，请退出客户端后再执行安装。

::warning
同一个发布页面通常包含多个系统的安装文件。请确认文件名称中包含 Windows 对应标识，避免下载 macOS 或 Linux 版本。
::
