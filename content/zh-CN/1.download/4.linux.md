## Linux 安装格式怎么选

| 格式 | 常见发行版 | 特点 |
| --- | --- | --- |
| `.deb` | Ubuntu、Debian、Linux Mint | 可通过系统包管理器安装 |
| `.rpm` | Fedora、RHEL、openSUSE | 适合使用 RPM 包管理的发行版 |
| `.AppImage` | 大多数桌面发行版 | 无需传统安装，添加执行权限后运行 |

处理器架构仍需对应：普通 Intel、AMD 电脑通常选择 `x64` 或 `amd64`，ARM 设备选择 `arm64` 或 `aarch64`。

没有桌面环境的 Linux 服务器，或偏好命令行管理的用户，可以选择 **Clash for Linux Install**，通过脚本安装并管理 Mihomo / Clash、订阅、Web 面板和 TUN 模式。

## AppImage 运行方式

下载后为文件添加执行权限：

```bash
chmod +x ./client.AppImage
```

然后双击文件，或在终端中运行：

```bash
./client.AppImage
```

::warning
不同桌面环境对系统托盘、开机启动和权限管理的支持可能不同。遇到界面无法显示时，请先确认系统依赖和桌面环境兼容性。
::
