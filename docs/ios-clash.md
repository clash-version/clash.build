# 苹果手机如何使用 Clash？(iOS 客户端下载指南)

由于 App Store 中国区的政策限制，Clash 及其相关代理软件无法在中国区下载。要在 iPhone 或 iPad 上使用 Clash，你需要：
1.  拥有一个**非中国区 Apple ID**（如美区、港区）。
2.  在 App Store 登录该 ID 下载客户端。
3.  购买或获取 [Clash 订阅链接](/how-choose-service)。

## 🚀 详细安装与使用步骤

### 第一步：获取非国区 Apple ID
你需要一个美区或其他地区的 Apple ID。
- **方案 A (推荐)**：自行注册。需要一个未注册过 Apple ID 的邮箱和对应地区的手机号（部分地区可选无）。
- **方案 B**：购买成品号。网上有专门出售美区 ID 的商家，几块钱一个，方便快捷。**注意：购买后请只在 App Store 登录，切勿在 iCloud 设置中登录，以免锁机风险！**

### 第二步：下载客户端
1. 打开 **App Store**。
2. 点击右上角头像，拉到最下方点击 **退出登录**。
3. 输入你的非国区 Apple ID 和密码登录。
4. 搜索 `Showadrocket` 或 `Stash` 进行下载（付费软件需先充值或购买礼品卡）。

### 第三步：导入订阅
以 **Showadrocket (小伙箭)** 为例：
1. 购买或获取你的 [Clash 订阅链接](/how-choose-service)。
2. 打开 Showadrocket，点击右上角 `+` 号。
3. 类型选择 `Subscribe` (订阅)。
4. 在 `URL` 栏粘贴你的订阅链接，`Remark` (备注) 随便填。
5. 点击完成，软件会自动更新节点列表。
6. 选择一个节点，开启顶部的开关即可上网。

以 **Stash** 为例：
1. 复制你的 Clash 订阅链接。
2. 打开 Stash，进入 `订阅列表` -> `从 URL 下载`。
3. 粘贴链接并下载。
4. 回到首页，点击 `启动`。

## ❓ 常见问题

### Q: 为什么搜不到 Clash？
A: Clash 原作者未开发 iOS 版本。iOS 上通常使用兼容 Clash 订阅的软件，如 Stash (官方称 Clash for iOS) 或 Showadrocket。

### Q: 免费的 Potatso Lite 还能用吗？
A: Potatso Lite 功能较为简陋，且已久未更新。推荐使用完整版 Potatso 或其他客户端。

### Q: 怎么给美区 ID 充值买软件？
A: 可以通过支付宝购买美区 App Store 充值卡（礼品卡），或者在淘宝/闲鱼购买兑换码。
