## 常见问题

### GitHub 直连打不开怎么办？
目前从中国大陆直接访问 GitHub 非常不稳定。建议使用 GitHub 加速链接下载，或在网络畅通后从官方源获取。

### 软件会有木马吗？
本站版本号实时同步 GitHub，无任何添加剂，请放心食用，如果不放心点击版本徽章可跳转官方发布页。多数客户端也支持应用内自动更新。

### 怎么使用？
每个客户端页面都有详细的图文教程，点击表格中的「教程」链接即可。也可参考 [快速入门指南](/quickly/install)，5 分钟搞定。

### 按教程配置，仍无法使用？
请依次排查：
1. 「系统代理」是否已开启
2. 配置文件是否成功导入（查看 [导入配置教程](/quickly/import)）
3. 节点是否可用（进行连通性测试）
4. 换个浏览器试试（推荐 Chrome、Edge、Safari）
5. 删除配置重新导入
6. 仍有问题？查看 [完整故障排除指南](/troubleshooting)

### 导入订阅失败怎么办？
提示"下载配置失败"或长时间无响应？
1. 先**关闭系统代理**，删除现有配置，重新导入，再打开代理
2. 部分地区（江苏、福建、河南等）订阅地址易受干扰，联系服务商获取备用地址
3. 详细解决方案见 [订阅导入失败排查](/troubleshooting#_1-检查订阅是否过期)

### 怎么测试节点是否可用？
点击节点页面的 🛜 或 ⚡ 图标进行连通性测试。显示数字的节点可用，显示超时（timeout）或失败的节点不可用。

### 所有节点timeout？
先尝试删除后重新导入配置文件。如仍然全部超时，请联系您的订阅服务商。

### 怎么选择节点？
新手建议使用默认设置，通常订阅已预设最优节点。进阶用户可参考 [代理分组详解](/proxy-groups) 了解节点分组逻辑。

### 开启代理，国内上网怎么变慢了？
可能是使用了全局模式，流量会绕路，试试规则模式。「规则模式」下国内流量直连，不走代理、不耗流量。了解更多模式区别请看 [代理模式详解](/proxy-modes)。

### 平常需要关闭Clash软件吗？
视情况而定，如果是`全局模式`，关闭代理能加速国内网站访问速度，如果是`规则模式`上网就不需要，当然我们的建议是用完就退出，可以节省一些后台程序消耗的网络流量。

### 某些网站打不开？
1. 检查该网站对应分组的节点是否可用
2. 尝试切换节点或使用「全局模式」
3. 了解分流规则：[Clash 规则详解](/clash-rules-explained)

### 使用后无法打开国内网站？
Windows 常见问题，解决方法：
1. 彻底退出软件（检查系统托盘）
2. 如仍无法访问：设置 → 网络和 Internet → 代理 → 关闭「使用代理服务器」
3. 详细步骤见 [故障排除](/troubleshooting)

#### Clash 内核是什么？
Clash 内核是代理功能的核心引擎，支持 SS、VMess、Trojan 等多种协议。原版已停更，目前主流客户端（如 Clash Verge、Clash Meta for Android）都采用更强大的 **Mihomo (Clash Meta)** 内核。[彻底搞懂Clash原理](/guide)

### 什么是 TUN 模式？
TUN 模式通过虚拟网卡接管所有流量，适合游戏加速或特殊应用。日常浏览用「系统代理」即可。详见 [虚拟网卡模式说明](/virtual-network-card)。

### 规则/全局/直连模式有什么区别？
- **规则模式**：智能分流，国内直连、国外走代理（推荐日常使用）
- **全局模式**：所有流量走代理
- **直连模式**：所有流量直连，相当于关闭代理

详细说明请看 [代理模式详解](/proxy-modes)。
