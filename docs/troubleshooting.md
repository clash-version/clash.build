# Clash 常见连接失败解决方案 (Troubleshooting)

如果你遇到了 Clash **“已开启系统代理但无法上网”**、**“节点全部超时(Timeout)”** 或 **“百度能开 Google 打不开”** 、**特定网站无法访问**、**开了代理访问还是慢**等问题，请按以下步骤逐一排查。

## 故障自查

### 订阅有效性检查
表现为节点全部timeout，打开订阅提供商官网，查看套餐是否到期，账号状态是否正常
### 是否手动改过DNS
表现为节点显示正常，无法访问网站，恢复默认的DNS解析
### 是否是特殊网络环境
表现为节点全部timeout，外地手机5G环境正常，比如：校园网，新疆、江苏、福建等特殊区域

## 客户端问题
### 协议不兼容
表现为无法读取配置文件异常，通常发生在相对较旧的Clash版本上，前往[下载中心](/download)下载最新版本的Clash
### 软件冲突
这种情况比较少见，比如端口冲突，安装了多个代理软件，解决办法关闭其他代理软件，一次只开一个代理软件。如果是跟其他软件冲突，可以退出所有代理软件，查看端口监听情况。如果存在端口监听，找到对应的应用关闭。
### Clash for Windows 常见问题
- **启动白屏/闪退**：删除 `C:\Users\用户名\.config\clash` 文件夹后重启
- **UWP 应用无法代理**：点击 General → UWP Loopback 勾选需要代理的应用
- **已停止维护**：建议迁移到 [Clash Verge](/clash-verge) 或 [FlClash](/flclash)

### Clash Verge 常见问题
- **TUN 模式无法开启**：以管理员身份运行，或点击设置 → 安装服务
- **macOS 提示无法验证开发者**：终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/Clash\ Verge.app`
- **内核启动失败**：检查端口是否被占用，或尝试重装客户端，参考[软件冲突](#软件冲突)

### FlClash 常见问题
- **Android 后台被杀**：关闭电池优化，锁定后台任务
- **Windows 启动慢**：正常现象，Flutter 框架冷启动需要几秒

### ClashMi 常见问题
- **iOS 无法安装**：需要使用非国区 Apple ID 下载
- **界面显示异常**：清除应用缓存后重启

## 商家问题
### 订阅域名被污染
表现为订阅更新失败，去官网重新导入，还是不行联系商家
### 订阅域名被墙
表现为命令行ping 订阅域名(xxxx.com),不显示延时，直接联系商家
### 节点不可用
表现为节点全部timeout，联系商家咨询
### 特定网站无法访问
商家分流规则问题，也可自行解决，找到新增规则的页面把需要访问的域名加入代理，指定出口即可


## 仍然无法解决？
联系订阅提供商家，大概率会给你解决方案
