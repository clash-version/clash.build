# 获取配置
在使用客户端之前，你需要获取配置地址。这通常由你的服务提供商提供。
 ## 1、复制地址

**Clash Verge Rev 仅是客户端工具，需要初始化配置方可联网。**

如果还没有订阅配置，[去选择订阅试用](/how-choose-service#_2026-精选-clash-订阅推荐)，登陆后找到`订阅地址`复制它。
