# ClashX Mac 版下载与详细订阅指南 (支持 M1/M2/Intel)

ClashX 是一款面向 macOS 的原生图形化客户端，基于 Clash 代理内核，提供订阅管理、规则分流、策略组与系统代理/TUN 等能力，适配 Apple Silicon 与 Intel 架构，侧重稳定、易用与与系统深度集成。

[官方仓库↗](https://github.com/clash-version/clashx)
