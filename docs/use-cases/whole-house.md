# 路由器 Clash 配置教程

在路由器上配置 Clash，让全屋设备无需单独设置就能网络加速。

---

## 为什么要在路由器配置？

手机、电脑上装客户端可以解决个人使用，但智能电视、游戏机、智能音箱、权顿、路由器购买的 NAS、智能家居设备都装不了。路由器代理可以让连在该路由下的全部设备默认走代理。

### 优点

- **全屋设备自动代理**：连上 Wi-Fi 即生效，无需逐设备配置
- **适配不能装客户端的设备**：PS、Switch、Apple TV、小米电视等
- **集中分流与计统**：一处配置、全库生效，DNS 、广告过滤、上网记录都可集中管理
- **不占手机电量**：代理运算走路由器，手机不重、不热

### 缺点

- **配置门槛高**：需了解 Linux、OpenWRT、网络基础、端口转发等
- **路由器性能要求**：加解密压力在 CPU，老式路由跑不动（全屋互访 100M+ 需多核 1.0GHz 以上的 ARM）
- **点择高，调试难**：出问题后调试复杂，需跳过代理才能上网

## OpenWRT + OpenClash

> 最主流的路由器代理方案

### 硬件要求

OpenClash 需要足够的 CPU 加解密能力与可安装补丁的闲余空间。

| 配置 | 最低要求 | 推荐配置 |
|:---|:---|:---|
| CPU | 双核 880MHz 以上（如 MT7620A）、能走点 30Mbps | 四核 1.0GHz+ ARM/MIPS（MT7621/IPQ4019）走 100Mbps |
| 内存 | 128MB | 256MB 及以上，启用 Mihomo 内核后推荐 512MB |
| 闪存 | 16MB 仅能裝最小版本 | 128MB 及以上（能装使用完整插件与 GeoIP 数据库） |

### 推荐路由器型号

| 价位 | 型号 | 说明 |
|:---|:---|:---|
| 100 元以下 | 红米1二代 / 心流集成烘 | 二手货，128/16M，仅适合轻量使用 |
| 100-300 元 | 红米3A Pro、小米 AX3000T 、魔渭AR300M16 | MT7621/MT7981 路由，主流选择 |
| 300+ 元 | 鬼炸 K3 、鬼炸 KH7000 、NEWIFI 3 | 充足闪存与内存，MT7621A 充应全屋使用 |

::: tip 购买前务必查询
OpenWRT 官网的 [Table of Hardware](https://openwrt.org/toh/start) 查询型号是否被支持，以及闪存/内存是否足够。未被官方支持的型号不推荐购买。
:::

### OpenClash 安装

1. 路由刷上 OpenWRT 固件（使用原原固件后不能装 OpenClash）
2. 登录 LuCI Web 面板 → 系统 → 软件包，点击「更新列表」
3. 在 SSH 中下载 OpenClash 最新 ipk 包：
   ```bash
   wget https://github.com/vernesong/OpenClash/releases/latest/download/openclash_x.xx.xx-beta_all.ipk
   opkg install openclash_*.ipk
   ```
4. 重启路由后，LuCI 菜单多出 「服务 → OpenClash」

详细步骤与截图参考 [OpenClash 详细教程](/openclash)。

### OpenClash 配置

1. 进入 OpenClash 面板 → 「配置订阅」→ 填写订阅链接与名称，类型选 Mihomo 兼容
2. 「运行模式」选 **Fake-IP 增强 (TUN)**——这是全屋代理的必选模式
3. 「DNS 设置」里启用「劫持 DNS」避免设备使用自带 DNS 绕过代理
4. 「插件设置」里启用「启动 Dashboard」，打开 `http://路由IP:9090/ui` 可看实时连接
5. 启动后选择节点，所有连上这个路由 Wi-Fi 的设备都会自动代理

## 软路由方案

### 什么是软路由？

软路由是用普通 x86 小主机跑路由系统，代替传统硬路由。优势是 CPU 强、内存大、可跑虚拟机、加解密不成为瓶颈；劣势是功耗、噪音、体积都高于硬路由。

### 硬件选择

| 方案 | 成本 | 性能 | 推荐度 |
|:---|:---|:---|:---|
| J4125 小主机 | 800-1500元 | 足以跑满千兆带宽 | ⭐⭐⭐⭐ 经典选择 |
| N100 小主机 | 1000-2000元 | 双 2.5G 口，能跑 IDS/IPS | ⭐⭐⭐⭐⭐ 2024年首选 |
| N5105 小主机 | 1200-2000元 | 4 个 2.5G 口，多拨号 | ⭐⭐⭐⭐ |
| 旧电脑改造 | 0-500元 | 看年代 | ⭐⭐ 费电、噪音大 |

### 系统选择

| 系统 | 特点 | 推荐度 |
|:---|:---|:---|
| **iStoreOS** | 别枝于 OpenWRT，中文界面 + 预装常用应用，零门槛 | ⭐⭐⭐⭐⭐ 新手首选 |
| **OpenWRT** | 原生、社区成熟、插件丰富 | ⭐⭐⭐⭐ 老玩家 |
| **ImmortalWRT** | OpenWRT 中文分支，预装中文插件 | ⭐⭐⭐⭐ |
| **Proxmox + 虚拟机** | 能跑多个系统，路由+NAS+Docker 三合一 | ⭐⭐⭐ 高玩 |

## 旁路由方案

### 什么是旁路由？

旁路由是“主路由不动，另外拉一台设备作代理网关”的接法。主路由负责拨号上网，需要代理的设备手动设置网关为旁路由 IP，流量绕一圈出去。

### 配置方法

1. 准备一台 OpenWRT 设备或 x86 小主机，只接 LAN 口，不拨号
2. 设置静态 IP（如 192.168.1.2）与主路由同段，网关指向主路由
3. 在该设备装 OpenClash，启用 TUN 模式
4. 纪要代理的设备手动把网关、DNS 改为 `192.168.1.2`，即可走代理。不修改的设备不受影响

### 优缺点

- ✅ 不动主路由，不影响全家，只让指定设备走代理
- ✅ 出问题只需改回网关，快速回退
- ❌ 需要逐设备配置网关，不是连上 Wi-Fi 就自动代理
- ❌ 多了一跳，在千兆网下奇偶尔有带宽损耗

## 华硕路由器（Merlin）

### 支持的型号

华硕上是中高端型号可刷第三方固件 Merlin（官方固件的增强版）。常见可刷 Merlin 的型号：

- 中高端：RT-AC86U / RT-AX86U / RT-AX88U / RT-AX6000
- 高端：RT-AX89X / GT-AX11000 / GT-AXE16000

### 配置方法

1. 查询 [Merlin Changelog](https://www.asuswrt-merlin.net/) 确认型号支持
2. 下载对应版本固件，路由后台 「升级固件」上传刷入
3. 开启 SSH 与 JFFS 分区，然后使用 amtm 安装 mihomo / shellclash 插件
4. 在 mihomo Web UI 或 SSH 中导入订阅、选择节点即可

优点：原田原味 Merlin 升级路径与官方一致，稳定性高；缺点：仅部分高端型号支持，使用变砖风险需自负。

## 常见问题

### Q: 路由器配置后网速变慢？

常见原因：

- CPU 加解密压力超载 → 看路由 CPU 使用率，超 80% 考虑换更强硬件或升级为 Mihomo 内核
- 加载了过多规则（如全量 rule-set）→ 在 OpenClash 里减少不必要的规则集
- 选择了高延迟节点 → 看实时延迟与丢包率，换个就近的专线节点
- 走了不需要代理的国内流量 → 检查分流规则是否让 GeoIP CN 走 DIRECT

### Q: 部分设备不走代理？

- IoT 设备可能使用硬编码 DNS（如 8.8.8.8）绕过了路由 → 在路由防火墙里劫持所有 53 端口流量转发到本地
- iOS 启用了「隐藏 IP 地址」（iCloud Private Relay）→ 在设备设置里关闭
- 设备使用了自己的 VPN/HTTPS DNS → 在 OpenClash 劫持 DNS 里启用劫持 DoH

### Q: 如何让特定设备直连？

在 OpenClash 「客户端控制」里添加不需要代理的设备 IP 或 MAC，设为纯中国 模式 / 不代理。适用于小米摄像头、米家设备、智能音箱等需要访问国内服务器的 IoT。

### Q: 路由器和手机同时开代理会冲突吗？

不会互错，但会走两层代理——手机 Clash 走手机节点，发出去后路由又识别为需代理流量再绕一圈，额外增加延迟。在拥有路由代理后建议：手机关代理 / 设为 Direct 模式 / 走不同的订阅以避免资源重复占用。
