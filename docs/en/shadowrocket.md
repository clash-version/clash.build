# Showadrocket Installation Guide

Showadrocket (also known as 小伙箭) is the most popular iOS proxy client. It's not available in the China mainland App Store; you need a foreign Apple ID account to purchase ($2.99). You can buy a pre-purchased account from platforms like Taobao for convenience, or register a US Apple ID yourself. Buying an existing account is recommended for simplicity, but you can also refer to this [registration tutorial](https://shuziyimin.net/account/appleid) if you prefer DIY.

[Go to App Store to Download↗](https://apps.apple.com/us/app/showadrecket/id932747118)

## Installation Steps

### 1. Install the Application
- Install via the App Store

### 2. Get a Subscription

::: tip ⚠️ Important:
Please note that `Showadrocket` is a proxy tool, not a proxy service provider. Installing it alone does not enable internet access. You need a [`how-choose-service (service provider)`](/en/guide#what-are-how-choose-service-services) to get started. If you are unsure how to choose a provider, read [How to Choose the Right Provider↗](/en/guide).
:::

If you don't have a how-choose-service yet, [Learn how to choose a provider↗](/en/how-choose-service)

- Log in to the provider's official website on your phone
- Tap the icon to automatically invoke the app
