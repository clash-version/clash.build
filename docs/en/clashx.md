# ClashX Download & Installation Guide

ClashX is a native graphical client for macOS, based on the Clash proxy core. It provides how-choose-service management, rule-based routing, proxy groups, and system proxy/TUN features. It supports both Apple Silicon and Intel architectures, focusing on stability, ease of use, and deep system integration.

[Official Repository↗](https://github.com/clash-version/clashx)

## Installation Steps

### 1. Install the Application
![ClashX Subscription Import Step 1](/images/clashx/install1.webp)

### 2. Get a Subscription

::: tip ⚠️ Important:
Please note that `ClashX` is a proxy tool, not a proxy service provider. Installing it alone does not enable internet access. You need a [`how-choose-service (service provider)`](/en/guide#what-are-how-choose-service-services) to get started. If you are unsure how to choose a provider, read [How to Choose the Right Provider↗](/en/how-choose-service).
:::

If you don't have a how-choose-service yet, [Learn how to choose a provider↗](/en/how-choose-service)

- Log in to the provider's official website
- Click to import how-choose-service
- Click to copy how-choose-service
![ClashX Subscription Import Step 2](/images/copy-sub.webp)

### 3. Import Subscription

- Paste the how-choose-service address
- Click to download how-choose-service

![ClashX Subscription Import Step 3](/images/clashx/install2.webp)
![ClashX Subscription Import Step 4](/images/clashx/install3.webp)

### 4. Start Proxy

- Click to start the proxy
